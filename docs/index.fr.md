# Codez sans angoisse de facturation. Des crédits qui n'expirent jamais, pas de limite horaire.

Claudin.io est un proxy API pour les agents de codage IA. Choisissez un **plan mensuel**, recevez un portefeuille de crédits qui se remplit chaque mois et dépensez-les à environ un crédit par requête — pas de facture par token, pas de limite horaire, et ce que vous n'utilisez pas reste à vous.

</div>

## Pourquoi Claudin.io

<div class="grid cards" markdown>

-   :material-wallet:{ .lg .middle } __Des crédits, pas un compteur__

    ---

    Un plan est un nombre de crédits par mois ; une requête typique en coûte
    environ un. Pas de limite horaire, pas de limite de session — le
    portefeuille est la seule limite, et une recharge le remplit instantanément.

-   :material-power-plug:{ .lg .middle } __Fonctionne avec vos outils__

    ---

    Endpoints compatibles OpenAI et Anthropic. Intégrez-le à OpenCode, Claude
    Code, Kilo Code, Zed, Codex, Cursor ou tout client OpenAI en quelques
    minutes.

-   :material-cash-multiple:{ .lg .middle } __Coût prévisible__

    ---

    Un prix mensuel fixe pour un nombre connu de crédits. Pas de surprise sur la
    facture en fin de mois, et les crédits inutilisés sont reportés — ils
    n'expirent jamais.

-   :material-format-list-bulleted:{ .lg .middle } __Un modèle que nous réglons, un catalogue si vous voulez choisir__

    ---

    `claudinio` est le modèle par défaut et notre recommandation — celui où vos
    crédits vont le plus loin. Huit modèles nommés sont à un réglage près,
    chacun un multiple fixe d'un crédit `claudinio`.

</div>

## Démarrez en 4 étapes

1. **[Créez un compte](getting-started/account.md)** et copiez votre clé API.
2. **[Définissez votre clé API](getting-started/set-your-key.md)** une fois dans votre shell.
3. **[Connectez votre outil](clients/opencode.md)** — choisissez votre éditeur ou agent.
4. **[Faites votre premier appel](getting-started/first-call.md)** et commencez à construire.

!!! tip "Le nom du modèle est `claudinio`"
    Quel que soit le client, l'id de modèle que vous visez est **`claudinio`**
    — ou un [id du catalogue](plans.md#le-catalogue-choisir-un-modele-par-son-nom)
    quand vous voulez un modèle précis. L'URL de base est **`https://api.claudin.io`**.
