# 요금제 및 제한

모든 Claudin.io 요금제는 **지출 보호 한도**가 있는 **무제한 사용**입니다.
토큰이나 요청당 청구되지 않습니다 — 고정 월 가격을 지불하고 자유롭게 사용합니다.
한도는 통제 불능의 에이전트(예: 무한 도구 루프)가 요금제를 소진하는 것을 막기 위해서만 존재합니다.

## 요금제

| 요금제 | 가격 | 지출 보호 | 가장 적합한 용도 |
| --- | --- | --- | --- |
| **스타터** | $5 / 월 | $0.50 / 시간 | 사용해보기 — 낮은 약정 |
| **라이트** | $9 / 월 | $1.00 / 시간 | 취미 프로젝트, 가끔 코딩 |
| **에센셜** | $19 / 월 또는 $189 / 년 | $2.00 / 시간 | 일상 코딩 — 인기 있는 선택 |
| **프로** ★ | $39 / 월 또는 $389 / 년 | $4.00 / 시간 | 무거운 에이전트 워크플로우 |
| **파워** | $59 / 월 또는 $589 / 년 | $6.00 / 시간 | 팀, 여러 프로젝트 |
| **울트라** | $99 / 월 또는 $989 / 년 | $10.00 / 시간 | 최대 성능, 팀 및 프로덕션 |

!!! 팁 "대부분의 사람들은 한도에 도달하지 않습니다"
    시간당 한도는 일반적인 대화형 작업에 충분합니다. 에이전트가 좁은 루프에
    빠졌을 때만 부딪히게 됩니다 — 바로 브레이크가 *필요한* 때입니다.

## 지출 보호 작동 방식

각 요금제는 예산 **윈도우** — 롤링 기간과 그 안의 최대 지출을 정의합니다:

- **스타터**, **라이트**, **에센셜**, **프로**, **파워**, **울트라**는 **1시간** 윈도우를 사용합니다.

윈도우 내에서 사용량에 따라 작은 내부 비용이 누적됩니다. 그 내부 비용이
윈도우 한도에 도달하면 윈도우가 재설정될 때까지 요청이 일시 중지됩니다.

모델 호출만 프록시를 통과합니다. 각 요청은 사용된 토큰을 기준으로 현재
윈도우의 누적 총액에 추가됩니다. 윈도우가 재설정되면 총액도 재설정됩니다.

한도에 도달하여 예산 오류가 발생하면 두 가지 옵션이 있습니다:

1. 윈도우가 재설정될 때까지 기다립니다 (대시보드에 표시됨).
2. 더 큰 한도를 위해 상위 요금제로 업그레이드합니다.

예산 오류가 어떻게 표시되는지 보려면 [요금제 관련 오류](api-reference.md#errors)를 참조하세요.
