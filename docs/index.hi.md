# बिल की चिंता के बिना कोड करें। क्रेडिट, सीमाएं नहीं।

Claudin.io AI कोडिंग एजेंटों के लिए एक API प्रॉक्सी है। एक **मासिक योजना** चुनें, हर महीने भरने वाला क्रेडिट वॉलेट पाएं, और उसे प्रति अनुरोध लगभग एक क्रेडिट पर खर्च करें — कोई प्रति-टोकन बिल नहीं, कोई प्रति-घंटा सीमा नहीं। आपकी योजना के क्रेडिट हर महीने नवीनीकृत होते हैं — वे उस महीने का कोटा हैं और जमा नहीं होते। टॉप-अप के रूप में खरीदे गए क्रेडिट कभी समाप्त नहीं होते।

## Claudin.io क्यों

<div class="grid cards" markdown>

-   :material-wallet:{ .lg .middle } __क्रेडिट, मीटर नहीं__

    ---

    एक योजना प्रति माह क्रेडिट की एक संख्या है; एक सामान्य अनुरोध लगभग एक
    क्रेडिट का होता है। कोई प्रति-घंटा सीमा नहीं, कोई सत्र सीमा नहीं — वॉलेट ही
    एकमात्र सीमा है, और एक टॉप-अप उसे तुरंत भर देता है।

-   :material-power-plug:{ .lg .middle } __आपके टूल के साथ काम करता है__

    ---

    OpenAI- और Anthropic-संगत एंडपॉइंट। इसे मिनटों में OpenCode, Claude Code,
    Kilo Code, Zed, Codex, Cursor या किसी भी OpenAI क्लाइंट में जोड़ें।

-   :material-cash-multiple:{ .lg .middle } __पूर्वानुमेय लागत__

    ---

    ज्ञात संख्या में क्रेडिट के लिए एक निश्चित मासिक कीमत। महीने के अंत में बिल
    में कोई आश्चर्य नहीं। योजना के क्रेडिट हर बिल के साथ नवीनीकृत होते हैं और जमा
    नहीं होते; टॉप-अप के रूप में खरीदे गए क्रेडिट कभी समाप्त नहीं होते।

-   :material-format-list-bulleted:{ .lg .middle } __एक मॉडल जिसे हम ट्यून करते हैं, एक कैटलॉग जब आप चुनना चाहें__

    ---

    `claudinio` डिफ़ॉल्ट और हमारी सिफ़ारिश है — वह मॉडल जिस पर आपके क्रेडिट सबसे
    दूर जाते हैं। आठ नामित मॉडल एक सेटिंग की दूरी पर हैं, हर एक `claudinio`
    क्रेडिट का निश्चित गुणक।

</div>

## 4 चरणों में शुरू करें

1. **[खाता बनाएं](getting-started/account.md)** और अपनी API कुंजी कॉपी करें।
2. **[अपनी API कुंजी सेट करें](getting-started/set-your-key.md)** — अपने शेल में एक बार।
3. **[अपना टूल जोड़ें](clients/opencode.md)** — अपना एडिटर या एजेंट चुनें।
4. **[अपनी पहली कॉल करें](getting-started/first-call.md)** और बनाना शुरू करें।

!!! tip "मॉडल का नाम `claudinio` है"
    आप जो भी क्लाइंट इस्तेमाल करें, जिस मॉडल आईडी की ओर आप इशारा करते हैं वह
    **`claudinio`** है — या जब आप कोई विशिष्ट मॉडल चाहें तो एक
    [कैटलॉग आईडी](plans.md#catalogue)। बेस URL **`https://api.claudin.io`** है।
