# बिना बिल चिंता के कोड करें। फ्लैट मासिक मूल्य, असीमित उपयोग।

Claudin.io एआई कोडिंग एजेंटों के लिए एक API प्रॉक्सी है। **फ्लैट मासिक सब्सक्रिप्शन** का भुगतान करें और जितना चाहें उपयोग करें — कोई प्रति-टोकन बिलिंग नहीं, कोई अनुरोध काउंटर नहीं, कोई क्रेडिट जो समाप्त हो जाते हैं।

</div>

## क्यों Claudin.io

<div class="grid cards" markdown>

-   :material-infinity:{ .lg .middle } __असीमित उपयोग__

    ---

    कोई अनुरोध गणना नहीं, कोई टोकन मीटरिंग नहीं। एकमात्र सुरक्षा एक प्रति-अवधि **व्यय सुरक्षा** सीमा है जो भागते हुए एजेंट को रोकती है — आप सामान्य काम में लगभग कभी इससे नहीं टकराते।

-   :material-power-plug:{ .lg .middle } __आपके टूल्स के साथ काम करता है__

    ---

    OpenAI- और Anthropic-संगत एंडपॉइंट। इसे मिनटों में OpenCode, Claude Code, Kilo Code, Zed, Codex, Cursor, या किसी भी OpenAI क्लाइंट में डालें।

-   :material-cash-multiple:{ .lg .middle } __पूर्वानुमानित लागत__

    ---

    एक निश्चित सब्सक्रिप्शन। महीने के अंत में कोई आश्चर्यजनक बिल नहीं, कोई "यह रिफैक्टर कितना खर्च करेगा?" चिंता नहीं।

-   :material-shield-check:{ .lg .middle } __अंतर्निहित व्यय सुरक्षा__

    ---

    एक कैस्केडिंग प्रति-अवधि बजट सीमा आपको इनफिनिट-लूप एजेंटों से बचाती है जो आपकी योजना को जला रहे हैं। पारदर्शी और आपके डैशबोर्ड में लाइव दिखाया गया है।

</div>

## 4 चरणों में शुरू करें

1. **[खाता बनाएं](getting-started/account.md)** और अपनी API कुंजी कॉपी करें।
2. **[अपनी API कुंजी सेट करें](getting-started/set-your-key.md)** अपने शेल में एक बार।
3. **[अपना टूल कनेक्ट करें](clients/opencode.md)** — अपना एडिटर या एजेंट चुनें।
4. **[अपनी पहली कॉल करें](getting-started/first-call.md)** और बिल्डिंग शुरू करें।

!!! tip "मॉडल का नाम हमेशा `claudinio` है"
    आप जो भी क्लाइंट उपयोग करते हैं, मॉडल आईडी जो आप इंगित करते हैं वह **`claudinio`** है।
    बेस URL **`https://api.claudin.io`** है।
