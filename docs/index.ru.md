# Пишите код без страха перед счётом. Кредиты, а не лимиты.

Claudin.io — API-прокси для ИИ-агентов программирования. Выберите **месячный тариф**, получите кошелёк с кредитами, который пополняется каждый месяц, и тратьте их примерно по одному кредиту за запрос — никакой оплаты за токен, никакого почасового лимита. Кредиты тарифа обновляются каждый месяц — это лимит текущего месяца, и они не накапливаются. Кредиты, купленные пополнением, никогда не сгорают.

## Почему Claudin.io

<div class="grid cards" markdown>

-   :material-wallet:{ .lg .middle } __Кредиты, а не счётчик__

    ---

    Тариф — это число кредитов в месяц; типичный запрос стоит около одного.
    Нет почасового лимита, нет лимита сессии — кошелёк единственный предел, и
    пополнение наполняет его мгновенно.

-   :material-power-plug:{ .lg .middle } __Работает с вашими инструментами__

    ---

    Совместимые с OpenAI и Anthropic эндпоинты. Подключите к OpenCode, Claude
    Code, Kilo Code, Zed, Codex, Cursor или любому OpenAI-клиенту за минуты.

-   :material-cash-multiple:{ .lg .middle } __Предсказуемая стоимость__

    ---

    Фиксированная месячная цена за известное число кредитов. Никаких
    сюрпризов в счёте в конце месяца. Кредиты тарифа обновляются с каждым
    счётом и не накапливаются; кредиты, купленные пополнением, никогда не
    сгорают.

-   :material-format-list-bulleted:{ .lg .middle } __Одна модель, которую мы настраиваем, и каталог, если хотите выбирать__

    ---

    `claudinio` — по умолчанию и наша рекомендация: модель, с которой ваши
    кредиты уходят дальше всего. Восемь именованных моделей в одной настройке,
    каждая — фиксированное кратное кредита `claudinio`.

</div>

## Начните за 4 шага

1. **[Создайте аккаунт](getting-started/account.md)** и скопируйте API-ключ.
2. **[Задайте API-ключ](getting-started/set-your-key.md)** — один раз в оболочке.
3. **[Подключите инструмент](clients/opencode.md)** — выберите редактор или агента.
4. **[Сделайте первый вызов](getting-started/first-call.md)** и начинайте.

!!! tip "Имя модели — `claudinio`"
    Какой бы клиент вы ни использовали, id модели, на который вы указываете, —
    **`claudinio`** — или [id из каталога](plans.md#catalogue), когда нужна
    конкретная модель. Базовый URL — **`https://api.claudin.io`**.
