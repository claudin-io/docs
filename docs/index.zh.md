## 为什么选择 Claudin.io

<div class="grid cards" markdown>

-   :material-infinity:{ .lg .middle } __无限使用__

    ---

    没有请求计数，没有 token 计量。唯一的保护机制是一个**每期支出保护**上限，用于阻止失控的代理——正常工作下几乎不会触及。

-   :material-power-plug:{ .lg .middle } __适配你的工具__

    ---

    兼容 OpenAI 和 Anthropic 的接口。几分钟内即可接入 OpenCode、Claude Code、Kilo Code、Zed、Codex、Cursor 或任何 OpenAI 客户端。

-   :material-cash-multiple:{ .lg .middle } __成本可预测__

    ---

    固定订阅费。月末不会收到意外账单，不再有“这次重构要花多少钱”的焦虑。

-   :material-shield-check:{ .lg .middle } __内置支出保护__

    ---

    级联的每期预算上限可防止无限循环的代理消耗你的套餐。透明展示，仪表盘实时显示。

</div>

## 四个步骤开始使用

1. **[创建账户](getting-started/account.md)** 并复制你的 API 密钥。
2. **[设置 API 密钥](getting-started/set-your-key.md)**，在 shell 中配置一次即可。
3. **[连接工具](clients/opencode.md)**——选择你的编辑器或代理。
4. **[发起你的第一个请求](getting-started/first-call.md)**，开始构建。

!!! tip "模型名称固定为 `claudinio`"
    无论使用什么客户端，指向的模型 ID 都是 **`claudinio`**。基础 URL 为 **`https://api.claudin.io`**。
