# 告别账单焦虑。用积分，而非上限。

Claudin.io 是面向 AI 编程代理的 API 代理。选择一个**月度套餐**，获得一个每月补充的积分钱包，以每次请求约 1 积分使用 — 不按 token 计费，没有每小时上限。套餐积分每月更新 — 它是当月的额度，不会累积。通过充值购买的积分永不过期。

## 为什么选择 Claudin.io

<div class="grid cards" markdown>

-   :material-wallet:{ .lg .middle } __积分，而非计量表__

    ---

    套餐就是每月的积分数；一次典型请求约消耗 1 个。没有每小时上限，没有会话
    上限 — 钱包是唯一的上限，一次充值即可立刻补满。

-   :material-power-plug:{ .lg .middle } __适配你的工具__

    ---

    兼容 OpenAI 和 Anthropic 的端点。几分钟内接入 OpenCode、Claude Code、Kilo
    Code、Zed、Codex、Cursor 或任何 OpenAI 客户端。

-   :material-cash-multiple:{ .lg .middle } __可预测的成本__

    ---

    固定月费换取确定数量的积分。月底账单没有意外。套餐积分随每张账单更新，不会累积；
    通过充值购买的积分永不过期。

-   :material-format-list-bulleted:{ .lg .middle } __一个我们调优的模型，想选时有目录__

    ---

    `claudinio` 是默认，也是我们的推荐 — 你的积分走得最远的模型。八个具名模型
    只差一个设置，每个都是 `claudinio` 积分的固定倍数。

</div>

## 4 步开始

1. **[创建账户](getting-started/account.md)** 并复制你的 API 密钥。
2. **[设置 API 密钥](getting-started/set-your-key.md)** — 在 shell 里设置一次。
3. **[连接你的工具](clients/opencode.md)** — 选择你的编辑器或代理。
4. **[发起第一次调用](getting-started/first-call.md)** 并开始构建。

!!! tip "模型名称是 `claudinio`"
    无论使用哪个客户端，你指向的模型 ID 都是 **`claudinio`** — 想要特定模型时
    则用[目录 ID](plans.md#catalogue)。基础 URL 是 **`https://api.claudin.io`**。
