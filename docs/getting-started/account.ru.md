# Создайте аккаунт

Получение рабочего API-ключа занимает около минуты.

## 1. Войдите через GitHub

Перейдите на **[claudin.io](https://claudin.io)** и нажмите **Войти через GitHub**.
Claudin.io использует GitHub для входа — не нужно запоминать отдельный пароль.

При первом входе ваш аккаунт автоматически создается на тарифе **Free**, так что вы можете попробовать всё, прежде чем платить.

## 2. Сгенерируйте API-ключ

Когда вы окажетесь в [панели управления](https://claudin.io/dashboard):

1. Найдите карточку **API Keys**.
2. Нажмите **Generate key** (или **Create new key**).
3. Скопируйте ключ — он выглядит как `sk-...`.

!!! warning "Относитесь к ключу как к паролю"
    Ваш API-ключ предоставляет доступ к бюджету вашего тарифа. Не сохраняйте его
    в репозиторий, не вставляйте в публичные чаты и не передавайте никому. Если
    ключ утек, отзовите его в панели управления и создайте новый.

## 3. Запомните два значения, которые понадобятся

Каждой интеграции нужны одни и те же два значения:

| Значение | Что это |
| --- | --- |
| **Base URL** | `https://api.claudin.io` |
| **Model** | `claudinio` |
| **API key** | `sk-...`, который вы только что скопировали |

Вот и всё. Далее либо [сделайте прямой API-запрос](first-call.md), чтобы убедиться, что всё работает, либо переходите сразу к [подключению вашего инструмента](../clients/claude-code.md).

---

## Выбор тарифа

Вы можете остаться на **Free**, чтобы попробовать. Когда будете готовы к большему, обновите тариф из панели управления — подробности в разделе [Тарифы и лимиты](../plans.md).

Обновления обрабатываются через Stripe и вступают в силу немедленно.
