# আপনার API কী সেট করুন

আপনার Claudin.io কী **একবার** একটি এনভায়রনমেন্ট ভেরিয়েবল হিসেবে সেট করুন এবং এই গাইডের প্রতিটি টুল এটি পুনরায় ব্যবহার করতে পারবে — প্রতিটি ক্লায়েন্টে হাতে হাতে পেস্ট করার প্রয়োজন নেই।

আপনার `sk-...` কী [ড্যাশবোর্ড](https://claudin.io/dashboard) থেকে নিন ([আপনার অ্যাকাউন্ট তৈরি করুন](account.md) দেখুন), তারপর এটি আপনার শেল প্রোফাইলে যোগ করুন যাতে এটি প্রতিটি নতুন টার্মিনালে উপলব্ধ থাকে।

## macOS / Linux

=== "zsh (macOS-এ ডিফল্ট)"

    ```bash
    echo 'export CLAUDINIO_API_KEY="sk-..."' >> ~/.zshrc
    source ~/.zshrc
    ```

=== "bash"

    ```bash
    echo 'export CLAUDINIO_API_KEY="sk-..."' >> ~/.bashrc
    source ~/.bashrc
    ```

`sk-...` আপনার আসল কী দিয়ে প্রতিস্থাপন করুন। আপনি কোন শেলে আছেন তা নিশ্চিত নন? `echo $SHELL` চালান।

## যাচাই করুন

```bash
echo $CLAUDINIO_API_KEY
```

আপনার কী প্রিন্ট হয়ে ফিরে আসা উচিত। যদি এটি খালি হয়, একটি নতুন টার্মিনাল খুলুন বা উপরের `source` কমান্ডটি পুনরায় চালান।

## কেন এটি সাহায্য করে

[আপনার টুল সংযুক্ত করুন](../clients/opencode.md) বিভাগের প্রতিটি **দ্রুত সেটআপ** স্ক্রিপ্ট `$CLAUDINIO_API_KEY` পড়ে, তাই এটি এক্সপোর্ট করার পরে আপনি যেকোনোটি সেভাবেই চালাতে পারেন — প্রতিস্থাপনের জন্য কোনো `YOUR_API_KEY` নেই। যে টুলগুলি সরাসরি এনভায়রনমেন্ট ভেরিয়েবল পড়ে (Codex-এর `env_key`, যেকোনো OpenAI-সামঞ্জস্যপূর্ণ CLI) সেগুলিও স্বয়ংক্রিয়ভাবে এটি গ্রহণ করে।

!!! warning "আপনার কীকে পাসওয়ার্ডের মতো ব্যবহার করুন"
    এই কী যার কাছে আছে সে আপনার ক্রেডিট খরচ করতে পারে। আপনার `~/.zshrc` /
    `~/.bashrc` প্রকাশ্য রিপোতে কমিট করবেন না। কী ফাঁস হলে ড্যাশবোর্ডে বাতিল করে
    নতুন একটি এক্সপোর্ট করুন।
