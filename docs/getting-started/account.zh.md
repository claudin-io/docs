# 创建你的账户

获取一个可用的 API 密钥大约只需一分钟。

## 1. 使用 GitHub 登录

前往 **[claudin.io](https://claudin.io)**，点击 **使用 GitHub 登录**。
Claudin.io 使用 GitHub 进行登录——无需管理单独的密码。

首次登录时，你的账户会自动创建在 **Free** 计划下，因此你可以在付费前免费试用。

## 2. 生成你的 API 密钥

进入 [仪表盘](https://claudin.io/dashboard) 后：

1. 找到 **API Keys** 卡片。
2. 点击 **生成密钥**（或 **创建新密钥**）。
3. 复制密钥——它看起来像 `sk-...`。

!!! warning "将你的密钥视为密码"
    你的 API 密钥可以访问你计划内的预算。不要将其提交到仓库中、粘贴到公开聊天中或分享出去。如果密钥泄露，请从仪表盘撤销并生成一个新的。

## 3. 记下你需要用到的两个值

每次集成都需要下面这两样东西：

| 值 | 说明 |
| --- | --- |
| **Base URL** | `https://api.claudin.io` |
| **Model** | `claudinio` |
| **API key** | 你刚刚复制的 `sk-...` |

就是这样。接下来，你可以[发出原始 API 调用](first-call.md)来确认它是否正常工作，或者直接跳到[连接你的工具](../clients/claude-code.md)。

---

## 选择计划

你可以继续使用 **Free** 计划进行试用。当你需要更大的空间时，请从仪表盘升级——请参阅[计划与限制](../plans.md)获取完整详情。

升级通过 Stripe 处理，并立即生效。
