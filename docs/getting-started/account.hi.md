# अपना खाता बनाएं

एक काम करने वाली API कुंजी प्राप्त करने में लगभग एक मिनट लगता है।

## 1. GitHub से साइन इन करें

**[claudin.io](https://claudin.io)** पर जाएं और **GitHub से साइन इन करें** पर क्लिक करें।
Claudin.io लॉगिन के लिए GitHub का उपयोग करता है — प्रबंधित करने के लिए कोई अलग पासवर्ड नहीं है।

पहली बार साइन इन करने पर, आपका खाता **Free** योजना पर स्वचालित रूप से बन जाता है, ताकि आप कुछ भी भुगतान करने से पहले इसे आज़मा सकें।

## 2. अपनी API कुंजी जनरेट करें

एक बार जब आप [डैशबोर्ड](https://claudin.io/dashboard) पर हों:

1. **API Keys** कार्ड ढूंढें।
2. **Generate key** (या **Create new key**) पर क्लिक करें।
3. कुंजी कॉपी करें — यह `sk-...` जैसी दिखती है।

!!! warning "अपनी कुंजी को पासवर्ड की तरह समझें"
    आपकी API कुंजी आपकी योजना के क्रेडिट खर्च करती है। इसे किसी रिपो में कमिट न करें,
    सार्वजनिक चैट में पेस्ट न करें, या साझा न करें। अगर कोई कुंजी लीक हो जाए, तो
    उसे डैशबोर्ड से रद्द करें और नई बनाएं।

## 3. दो मान नोट करें जिनकी आपको आवश्यकता होगी

प्रत्येक एकीकरण को समान दो चीजों की आवश्यकता होती है:

| मान | यह क्या है |
| --- | --- |
| **Base URL** | `https://api.claudin.io` |
| **मॉडल** | `claudinio` |
| **API कुंजी** | वह `sk-...` जिसे आपने अभी कॉपी किया है |

बस इतना ही। इसके बाद, या तो [एक रॉ API कॉल करें](first-call.md) यह पुष्टि करने के लिए कि यह काम करता है, या सीधे [अपने टूल को कनेक्ट करें](../clients/claude-code.md) पर जाएं।
