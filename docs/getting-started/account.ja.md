# アカウントを作成する

有効なAPIキーの取得には約1分かかります。

## 1. GitHubでサインイン

**[claudin.io](https://claudin.io)** にアクセスし、**Sign in with GitHub** をクリックします。
Claudin.ioはログインにGitHubを使用します。別途パスワードを管理する必要はありません。

初回サインイン時には、**Free** プランでアカウントが自動的に作成されます。そのため、支払い前に試すことができます。

## 2. APIキーを生成する

[ダッシュボード](https://claudin.io/dashboard) に移動したら：

1. **API Keys** カードを見つけます。
2. **Generate key**（または **Create new key**）をクリックします。
3. キーをコピーします。`sk-...` のような形式です。

!!! warning "キーはパスワードのように扱ってください"
    APIキーはプランの予算にアクセスできます。リポジトリにコミットしたり、
    公開チャットに貼り付けたり、共有したりしないでください。キーが漏洩した場合は、ダッシュボードから
    失効させて新しいキーを生成してください。

## 3. 必要な2つの値を確認する

すべてのインテグレーションに必要なものは同じ2つです：

| 値 | 説明 |
| --- | --- |
| **ベースURL** | `https://api.claudin.io` |
| **モデル** | `claudinio` |
| **APIキー** | 先ほどコピーした `sk-...` |

以上です。次に、[生のAPI呼び出し](first-call.md) を行って動作を確認するか、[ツールの接続](../clients/claude-code.md) に直接進んでください。

## プランを選ぶ

**Free** プランのまま試すことができます。より多くの余裕が必要になったら、ダッシュボードからアップグレードしてください。詳細は [プランと制限](../plans.md) をご覧ください。

アップグレードはStripeを通じて処理され、即座に反映されます。
