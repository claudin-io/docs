# إنشاء حسابك

الحصول على مفتاح API يعمل يستغرق حوالي دقيقة.

## 1. تسجيل الدخول باستخدام GitHub

انتقل إلى **[claudin.io](https://claudin.io)** وانقر على **تسجيل الدخول باستخدام GitHub**.
يستخدم Claudin.io GitHub لتسجيل الدخول — ليست هناك حاجة لإدارة كلمة مرور منفصلة.

عند تسجيل الدخول لأول مرة، يتم إنشاء حسابك تلقائيًا على الخطة **المجانية**، لذا يمكنك تجربتها قبل الدفع.

## 2. إنشاء مفتاح API الخاص بك

بمجرد دخولك إلى [لوحة التحكم](https://claudin.io/dashboard):

1. ابحث عن بطاقة **مفاتيح API**.
2. انقر على **إنشاء مفتاح** (أو **إنشاء مفتاح جديد**).
3. انسخ المفتاح — يبدو مثل `sk-...`.

!!! warning "تعامل مع مفتاحك ككلمة مرور"
    مفتاح API الخاص بك ينفق رصيد خطتك. لا تودعه في مستودع، ولا تلصقه في دردشة
    عامة، ولا تشاركه. إن تسرّب مفتاح فألغِه من لوحة التحكم وأنشئ مفتاحًا جديدًا.

## 3. لاحظ القيمتين اللتين ستحتاجهما

كل تكامل يحتاج إلى نفس الشيئين:

| القيمة | ما هي |
| --- | --- |
| **عنوان URL الأساسي** | `https://api.claudin.io` |
| **النموذج** | `claudinio` |
| **مفتاح API** | `sk-...` الذي نسخته للتو |

هذا كل شيء. بعد ذلك، إما [إجراء استدعاء API خام](first-call.md) لتأكيد أنه يعمل، أو الانتقال مباشرة إلى [توصيل أداتك](../clients/claude-code.md).
