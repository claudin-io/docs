# আপনার অ্যাকাউন্ট তৈরি করুন

একটি কার্যকর API কী পেতে প্রায় এক মিনিট সময় লাগে।

## ১. GitHub দিয়ে সাইন ইন করুন

**[claudin.io](https://claudin.io)**-এ যান এবং **Sign in with GitHub**-এ ক্লিক করুন।
Claudin.io লগইনের জন্য GitHub ব্যবহার করে — আলাদা পাসওয়ার্ড পরিচালনা করার প্রয়োজন নেই।

প্রথমবার সাইন ইন করার সময়, আপনার অ্যাকাউন্ট **ফ্রি** প্ল্যানে স্বয়ংক্রিয়ভাবে তৈরি হয়, তাই কিছু দেওয়ার আগে আপনি এটি চেষ্টা করে দেখতে পারেন।

## ২. আপনার API কী তৈরি করুন

একবার আপনি [ড্যাশবোর্ডে](https://claudin.io/dashboard) এলে:

১. **API Keys** কার্ডটি খুঁজুন।
২. **কী তৈরি করুন** (বা **নতুন কী তৈরি করুন**) ক্লিক করুন।
৩. কীটি কপি করুন — এটি দেখতে `sk-...` এর মতো।

!!! warning "আপনার কীকে পাসওয়ার্ডের মতো আচরণ করুন"
    আপনার API কী আপনার প্ল্যানের বাজেটে অ্যাক্সেস দেয়। এটি রিপোজিটরিতে কমিট করবেন না,
    পাবলিক চ্যাটে পেস্ট করবেন না, বা শেয়ার করবেন না। যদি একটি কী ফাঁস হয়, ড্যাশবোর্ড থেকে এটি রিভোক করুন
    এবং একটি নতুন কী তৈরি করুন।

## ৩. আপনার প্রয়োজনীয় দুটি মান নোট করুন

প্রতিটি ইন্টিগ্রেশনের জন্য এই একই দুটি জিনিস প্রয়োজন:

| মান | এটি কী |
| --- | --- |
| **বেস URL** | `https://api.claudin.io` |
| **মডেল** | `claudinio` |
| **API কী** | আপনি এইমাত্র কপি করা `sk-...` |

এটাই। এরপর, হয় [একটি র API কল করুন](first-call.md) এটি কাজ করে কিনা নিশ্চিত করতে, অথবা সরাসরি [আপনার টুল সংযুক্ত করুন](../clients/claude-code.md)-এ চলে যান।

## একটি প্ল্যান নির্বাচন করা

আপনি **ফ্রি**-তে থাকতে পারেন জিনিসগুলি চেষ্টা করে দেখার জন্য। যখন আপনি আরও সক্ষমতার জন্য প্রস্তুত হন, ড্যাশবোর্ড থেকে আপগ্রেড করুন — সম্পূর্ণ বিবরণের জন্য [প্ল্যান ও সীমা](../plans.md) দেখুন।

আপগ্রেডগুলি Stripe-এর মাধ্যমে পরিচালিত হয় এবং তৎক্ষণাৎ কার্যকর হয়।
