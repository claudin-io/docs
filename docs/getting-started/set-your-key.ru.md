# Установите свой API-ключ

Установите свой ключ Claudin.io **один раз** как переменную окружения, и каждый инструмент в этом руководстве сможет его использовать — не нужно вставлять его в каждый клиент вручную.

Возьмите свой ключ `sk-...` из [панели управления](https://claudin.io/dashboard) (см. [Создайте учетную запись](account.md)), затем добавьте его в профиль вашей оболочки, чтобы он был доступен в каждом новом терминале.

## macOS / Linux

=== "zsh (по умолчанию в macOS)"

    ```bash
    echo 'export CLAUDINIO_API_KEY="sk-..."' >> ~/.zshrc
    source ~/.zshrc
    ```

=== "bash"

    ```bash
    echo 'export CLAUDINIO_API_KEY="sk-..."' >> ~/.bashrc
    source ~/.bashrc
    ```

Замените `sk-...` на ваш реальный ключ. Не уверены, какая у вас оболочка? Выполните `echo $SHELL`.

## Проверка

```bash
echo $CLAUDINIO_API_KEY
```

Вы должны увидеть ваш ключ в выводе. Если он пуст, откройте новый терминал или повторно выполните команду `source` выше.

## Почему это полезно

Каждый скрипт **Быстрой настройки** в разделе [Подключите свой инструмент](../clients/opencode.md) читает `$CLAUDINIO_API_KEY`, поэтому после его экспорта вы можете запускать любой из них как есть — не нужно заменять `YOUR_API_KEY`. Инструменты, которые напрямую читают переменные окружения (Codex's `env_key`, любой OpenAI-совместимый CLI), также подхватывают его автоматически.

!!! warning "Относитесь к своему ключу как к паролю"
    Любой, у кого есть этот ключ, может тратить бюджет вашего плана. Не добавляйте файлы `~/.zshrc` / `~/.bashrc` в публичный репозиторий. Если ключ утек, отзовите его в панели управления и экспортируйте новый.
