# اپنی API کلید سیٹ کریں

اپنی Claudin.io کلید **ایک بار** بطور ماحولی متغیر سیٹ کریں اور اس گائیڈ کا ہر ٹول اسے دوبارہ استعمال کر سکتا ہے — ہر کلائنٹ میں ہاتھ سے چسپاں کرنے کی ضرورت نہیں۔

اپنی `sk-...` کلید [ڈیش بورڈ](https://claudin.io/dashboard) سے حاصل کریں (دیکھیں [اپنا اکاؤنٹ بنائیں](account.md))، پھر اسے اپنے شیل پروفائل میں شامل کریں تاکہ یہ ہر نئے ٹرمینل میں دستیاب ہو۔

## macOS / Linux

=== "zsh (macOS پر ڈیفالٹ)"

    ```bash
    echo 'export CLAUDINIO_API_KEY="sk-..."' >> ~/.zshrc
    source ~/.zshrc
    ```

=== "bash"

    ```bash
    echo 'export CLAUDINIO_API_KEY="sk-..."' >> ~/.bashrc
    source ~/.bashrc
    ```

`sk-...` کو اپنی اصلی کلید سے بدلیں۔ یقین نہیں کہ آپ کون سا شیل استعمال کر رہے ہیں؟ `echo $SHELL` چلائیں۔

## تصدیق کریں

```bash
echo $CLAUDINIO_API_KEY
```

آپ کو اپنی کلید پرنٹ ہوتی دیکھنی چاہیے۔ اگر یہ خالی ہے تو، نیا ٹرمینل کھولیں یا اوپر والا `source` کمانڈ دوبارہ چلائیں۔

## یہ کیوں مددگار ہے

ہر **Quick setup** اسکرپٹ [Connect your tool](../clients/opencode.md) سیکشن میں `$CLAUDINIO_API_KEY` پڑھتا ہے، لہذا ایک بار ایکسپورٹ ہونے کے بعد آپ ان میں سے کسی کو بھی بغیر تبدیلی کے چلا سکتے ہیں — تبدیل کرنے کے لیے کوئی `YOUR_API_KEY` نہیں ہے۔ وہ ٹولز جو ماحولی متغیرات کو براہ راست پڑھتے ہیں (Codex کا `env_key`، کوئی بھی OpenAI-مطابق CLI) بھی خود بخود اسے اٹھا لیتے ہیں۔

!!! warning "اپنی کلید کو پاس ورڈ کی طرح سمجھیں"
    اس کلید کے ساتھ کوئی بھی آپ کے پلان کا بجٹ خرچ کر سکتا ہے۔ اپنی `~/.zshrc` / `~/.bashrc` کو عوامی ریپوزٹری میں کمٹ نہ کریں۔ اگر کلید لیک ہو جائے تو، ڈیش بورڈ میں اسے منسوخ کریں اور ایک نئی ایکسپورٹ کریں۔
