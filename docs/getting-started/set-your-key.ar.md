# تعيين مفتاح API الخاص بك

قم بتعيين مفتاح Claudin.io الخاص بك **مرة واحدة** كمتغير بيئة، وستتمكن كل أداة في هذا الدليل من إعادة استخدامه — لا حاجة للصقه يدويًا في كل عميل.

احصل على مفتاح `sk-...` الخاص بك من [لوحة التحكم](https://claudin.io/dashboard) (انظر [إنشاء حسابك](account.md))، ثم أضفه إلى ملف تعريف الصدفة الخاص بك بحيث يكون متاحًا في كل نافذة طرفية جديدة.

## macOS / Linux

=== "zsh (الافتراضي على macOS)"

    ```bash
    echo 'export CLAUDINIO_API_KEY="sk-..."' >> ~/.zshrc
    source ~/.zshrc
    ```

=== "bash"

    ```bash
    echo 'export CLAUDINIO_API_KEY="sk-..."' >> ~/.bashrc
    source ~/.bashrc
    ```

استبدل `sk-...` بمفتاحك الفعلي. لست متأكدًا من الصدفة التي تستخدمها؟ شغّل `echo $SHELL`.

## التحقق

```bash
echo $CLAUDINIO_API_KEY
```

يجب أن ترى المفتاح مطبوعًا. إذا كان فارغًا، افتح نافذة طرفية جديدة أو أعد تشغيل أمر `source` أعلاه.

## لماذا هذا مفيد

كل نص **إعداد سريع** في قسم [توصيل أداتك](../clients/opencode.md) يقرأ `$CLAUDINIO_API_KEY`، لذا بمجرد تصديره يمكنك تشغيل أي منها كما هو — لا حاجة لاستبدال `YOUR_API_KEY`. الأدوات التي تقرأ متغيرات البيئة مباشرة (مثل `env_key` الخاص بـ Codex، وأي واجهة CLI متوافقة مع OpenAI) ستلتقطه تلقائيًا أيضًا.

!!! warning "تعامل مع مفتاحك ككلمة مرور"
    أي شخص يملك هذا المفتاح يمكنه إنفاق رصيد خطتك. لا تضع ملف `~/.zshrc` أو `~/.bashrc` في مستودع عام. إذا تسرب المفتاح، قم بإبطاله من لوحة التحكم وقم بتصدير مفتاح جديد.

---

هل قمت بتصدير المفتاح؟ الآن [قم بإجراء أول استدعاء](first-call.md) أو انتقل مباشرة إلى [توصيل أداتك](../clients/opencode.md).
