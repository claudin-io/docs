# اپنا اکاؤنٹ بنائیں

API کلید حاصل کرنے میں تقریباً ایک منٹ لگتا ہے۔

## 1. GitHub کے ساتھ سائن ان کریں

**[claudin.io](https://claudin.io)** پر جائیں اور **Sign in with GitHub** پر کلک کریں۔
Claudin.io لاگ ان کے لیے GitHub استعمال کرتا ہے — اس کے لیے الگ پاس ورڈ کا انتظام کرنے کی ضرورت نہیں ہے۔

پہلی بار سائن ان کرنے پر، آپ کا اکاؤنٹ **Free** پلان پر خود بخود بن جاتا ہے، تاکہ آپ کچھ بھی ادا کرنے سے پہلے اسے آزما سکیں۔

## 2. اپنی API کلید بنائیں

ایک بار جب آپ [dashboard](https://claudin.io/dashboard) پر ہوں:

1. **API Keys** کارڈ تلاش کریں۔
2. **Generate key** (یا **Create new key**) پر کلک کریں۔
3. کلید کاپی کریں — یہ `sk-...` کی طرح نظر آتی ہے۔

!!! warning "اپنی کلید کو پاس ورڈ کی طرح سمجھیں"
    آپ کی API کلید آپ کے منصوبے کے کریڈٹس خرچ کرتی ہے۔ اسے کسی ریپو میں کمٹ نہ
    کریں، عوامی چیٹ میں پیسٹ نہ کریں، یا شیئر نہ کریں۔ اگر کوئی کلید لیک ہو جائے تو
    اسے ڈیش بورڈ سے منسوخ کریں اور نئی بنائیں۔

## 3. ان دو اقدار کو نوٹ کریں جن کی آپ کو ضرورت ہوگی

ہر انٹیگریشن کو ایک جیسی دو چیزوں کی ضرورت ہوتی ہے:

| قدر | یہ کیا ہے |
| --- | --- |
| **Base URL** | `https://api.claudin.io` |
| **Model** | `claudinio` |
| **API key** | وہ `sk-...` جو آپ نے ابھی کاپی کیا |

بس اتنا ہی ہے۔ اگلا، یا تو [ایک خام API کال کریں](first-call.md) تاکہ تصدیق ہو سکے کہ یہ کام کرتا ہے، یا براہ راست [اپنے ٹول کو جوڑنے](../clients/claude-code.md) پر جائیں۔
