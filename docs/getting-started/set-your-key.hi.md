# अपनी API कुंजी सेट करें

अपनी Claudin.io कुंजी **एक बार** एक पर्यावरण चर के रूप में सेट करें और इस गाइड में प्रत्येक उपकरण इसका पुन: उपयोग कर सकता है — प्रत्येक क्लाइंट में इसे हाथ से चिपकाने की आवश्यकता नहीं है।

अपनी `sk-...` कुंजी [डैशबोर्ड](https://claudin.io/dashboard) से प्राप्त करें ([अपना खाता बनाएँ](account.md) देखें), फिर इसे अपने शेल प्रोफ़ाइल में जोड़ें ताकि यह हर नए टर्मिनल में उपलब्ध हो।

## macOS / Linux

=== "zsh (default on macOS)"

    ```bash
    echo 'export CLAUDINIO_API_KEY="sk-..."' >> ~/.zshrc
    source ~/.zshrc
    ```

=== "bash"

    ```bash
    echo 'export CLAUDINIO_API_KEY="sk-..."' >> ~/.bashrc
    source ~/.bashrc
    ```

`sk-...` को अपनी वास्तविक कुंजी से बदलें। पक्का नहीं कि आप किस शेल पर हैं? `echo $SHELL` चलाएँ।

## सत्यापित करें

```bash
echo $CLAUDINIO_API_KEY
```

आपको अपनी कुंजी वापस मुद्रित दिखनी चाहिए। यदि यह खाली है, तो एक नया टर्मिनल खोलें या ऊपर दिए गए `source` कमांड को फिर से चलाएँ।

## यह क्यों मदद करता है

इस गाइड के [अपना उपकरण कनेक्ट करें](../clients/opencode.md) अनुभाग में प्रत्येक **त्वरित सेटअप** स्क्रिप्ट `$CLAUDINIO_API_KEY` पढ़ती है, इसलिए एक बार इसे निर्यात करने के बाद आप किसी भी स्क्रिप्ट को ज्यों का त्यों चला सकते हैं — इसमें बदलने के लिए कोई `YOUR_API_KEY` नहीं है। वे उपकरण जो सीधे पर्यावरण चर पढ़ते हैं (Codex का `env_key`, कोई भी OpenAI-संगत CLI) भी इसे स्वचालित रूप से उठा लेते हैं।

!!! warning "अपनी कुंजी को पासवर्ड की तरह समझें"
    इस कुंजी वाला कोई भी व्यक्ति आपके क्रेडिट खर्च कर सकता है। अपनी `~/.zshrc` /
    `~/.bashrc` को सार्वजनिक रिपो में कमिट न करें। अगर कुंजी लीक हो जाए, तो उसे
    डैशबोर्ड में रद्द करें और नई एक्सपोर्ट करें।
