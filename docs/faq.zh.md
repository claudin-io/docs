# 常见问题

## Claudin.io 到底是什么？

面向 AI 编程代理的 API 代理。你支付一个月度套餐，获得一个每月补充的积分钱包和一个
兼容 OpenAI/Anthropic 的 API 密钥，可用于 Claude Code、Kilo、Zed、Codex、Cursor 或
任何 OpenAI 客户端。一次典型的编程请求约为 1 积分。不按 token 计费，没有每小时上限。

## 有上限吗？

只有你的钱包。没有每小时上限、没有会话上限、没有每周配额 — 唯一能让你的代理停下的
是空余额，而一次充值即可立刻解决。没用完的积分留在钱包里，永不过期。见
[套餐与积分](plans.md)。

## 为什么用积分而不是固定月费？

因为我们在真实流量上测量了固定月费套餐的每小时上限，它切断了 Pro 上每 10 个活跃
小时中的 1 个 — 是正在工作的人，不是失控的循环。一个卖给你却在你需要时用不了的
容量的套餐，形状就是错的。积分是你看得见的数字，一个重度小时由安静的小时来付，
一个重度月份只差一次充值而不是一次等待。

## 可以用于编程以外的事情吗？

API 兼容 OpenAI，所以技术上任何请求都能用。但这个服务是为 **AI 编程**打造的：路由、
提示词和缓存都针对编程代理调优。与编程无关的活动 — 通用聊天机器人、无代码自动化 —
可能会得到特殊路由，由与编程流量不同的模型或层级来处理。

## 我用的是哪个模型？

默认是 **`claudinio`**（需要 `provider/model` 形式的客户端用 `claudinio/claudinio`）。
基础 URL 是 `https://api.claudin.io`。它是我们为代码调优、测量和缓存的模型，也是你的
积分走得最远的模型。

## 可以选择别的模型吗？

可以，按名称选。`claudius` 是我们的高级选项，最多 6× 积分。
[目录](plans.md#catalogue)增加了八个第三方模型 — Claude Sonnet 5 和 Haiku 4.5、
Gemini 3.1 Pro、Kimi K3、GLM 5.3、MiniMax M3、Qwen3 Coder — 每个都按 `claudinio`
积分的固定倍数计价，从 3× 到 22×。在客户端设置 ID，只有那一次请求按倍数付费。
每个模型在每个套餐上都有；我们仍然推荐 `claudinio`。

## 用 `Authorization` 还是 `x-api-key` 认证？

两者都可以。`Authorization: Bearer YOUR_API_KEY` 或 `x-api-key: YOUR_API_KEY`。

## 可以用在未列出的工具上吗？

可以 — 任何允许自定义 OpenAI 基础 URL 的工具都能用。使用
[通用 OpenAI 配置](clients/openai-compatible.md)。

## 支持工具/函数调用吗？

支持。这就是它能在代理式编辑器中工作的原因。像 OpenAI API 一样传入 `tools` 并读取
`tool_calls`。

## 能处理图片、音频或视频吗？

能，且是透明的。发送标准的 OpenAI 内容块；代理会在模型看到之前把图片/音频/视频转换
成文字描述或转录。无需特别配置。

## 上下文窗口有多大？

256K token。

## 如何升级或取消？

在你的[仪表盘](https://claudin.io/dashboard)操作。升级即时生效（通过 Stripe）。
取消后，你的付费套餐保留到已付周期结束。已在钱包里的积分仍归你所有，套餐结束后
继续可用。

## 可以退款吗？

**首次付款后 48 小时内**可以 — 用你账户的邮箱写信至
[support@claudin.io](mailto:support@claudin.io)。订阅立即结束，你会拿回所付金额，
减去一笔覆盖你账户在此期间模型使用成本的使用与处理费（绝不超过你所付的金额）。
试了一天觉得不合适？几乎全额退回。两天用掉了整个月的积分？预期很少或没有。48 小时
后不再退款；取消会保留套餐到已付周期结束。完整条文见[条款](https://claudin.io/terms)。

## 我收到了 `402 insufficient_credits`。怎么办？

你的钱包空了。在仪表盘购买一次[充值](plans.md#top-ups)或换到更大的套餐 — 两者都
即时生效。没有排队，失败的请求也没有计费。

## 我的旧 Essential / Pro / Ultra 套餐会怎样？

它会和以前完全一样，带着每小时上限，一直运行到已付周期结束，之后不再续订。月付
订阅者已收到用于试用新系统的礼遇积分；年付订阅者保留整年，到期后转入积分。见
[旧套餐](plans.md#legacy-plans)。

## 请求以 401 失败。

你的密钥缺失或错误。从仪表盘重新复制，确保没有多余空格，并且设置了认证头。

## 我的密钥泄露了。怎么办？

在仪表盘吊销它并立即生成新的。像对待密码一样对待密钥 — 永远不要提交或公开分享。

## 哪里可以获得帮助？

在[仪表盘](https://claudin.io/dashboard)的**支持**卡片开一个工单，或给支持团队发
邮件。我们会回复你。
