# Cursor

[Cursor](https://cursor.com) আপনাকে তার সেটিংসের মাধ্যমে একটি OpenAI-সামঞ্জস্যপূর্ণ মডেল যোগ করার সুযোগ দেয়। Claudin.io OpenAI বেস URL ওভাররাইডের মাধ্যমে প্লাগ ইন হয়।

## সেটআপ

1. **Cursor → Settings → Models** (অথবা **Cursor Settings → AI**) খুলুন।
2. **OpenAI API Key** এ স্ক্রোল করুন এবং **Override OpenAI Base URL** অপশনটি প্রসারিত করুন।
3. সেট করুন:

    | ফিল্ড | মান |
    | --- | --- |
    | OpenAI API Key | `YOUR_API_KEY` |
    | Base URL | `https://api.claudin.io/v1` |

4. **Models** এর অধীনে, **`claudinio`** নামে একটি কাস্টম মডেল যোগ করুন এবং এটি সক্রিয় করুন।
5. আপনি যদি Cursor কে একচেটিয়াভাবে Claudin.io ব্যবহার করতে চান তবে অন্যান্য ডিফল্ট মডেলগুলি নিষ্ক্রিয় করুন।

!!! note "Cursor-এর নিজস্ব বৈশিষ্ট্য"
    Cursor-এর এজেন্টিক বৈশিষ্ট্যগুলি একটি OpenAI-সামঞ্জস্যপূর্ণ চ্যাট মডেলের সাথে সবচেয়ে ভালো কাজ করে।
    `claudinio` টুল কল সমর্থন করে, তাই Composer/Agent ফ্লোগুলি কাজ করে। কিছু Cursor-প্রোপ্রাইটারি বৈশিষ্ট্য (Tab অটোকমপ্লিট, ইত্যাদি) Cursor-এর নিজস্ব মডেলে চলে এবং আপনার প্রদানকারী ওভাররাইডের মাধ্যমে রুট করা হয় না।

## যাচাই করুন

Cursor-এ একটি চ্যাট খুলুন, **claudinio** নির্বাচন করুন এবং একটি বার্তা পাঠান। আপনি যদি উত্তর পান, তাহলে সব ঠিক আছে। যদি না পান, তবে বেস URL শেষে `/v1` আছে কিনা এবং কী-তে কোন অতিরিক্ত স্পেস নেই কিনা তা দুবার চেক করুন।

| সেটিং | মান |
| --- | --- |
| Base URL | `https://api.claudin.io/v1` |
| মডেল | `claudinio` |
