# کرسر

[کرسر](https://cursor.com) آپ کو اپنی ترتیبات کے ذریعے OpenAI کے مطابق ماڈل شامل کرنے دیتا ہے۔ Claudin.io OpenAI بنیادی URL اووررائڈ کے ذریعے پلگ ان ہوتا ہے۔

## سیٹ اپ

1. **کرسر → ترتیبات → ماڈلز** کھولیں (یا **کرسر ترتیبات → AI**)۔
2. **OpenAI API کلید** تک اسکرول کریں اور **OpenAI بنیادی URL اووررائڈ** آپشن کو پھیلائیں۔
3. سیٹ کریں:

    | فیلڈ | قدر |
    | --- | --- |
    | OpenAI API کلید | `YOUR_API_KEY` |
    | بنیادی URL | `https://api.claudin.io/v1` |

4. **ماڈلز** کے تحت، **`claudinio`** نامی ایک حسب ضرورت ماڈل شامل کریں اور اسے فعال کریں۔
5. اگر آپ چاہتے ہیں کہ کرسر صرف Claudin.io استعمال کرے تو دیگر ڈیفالٹ ماڈلز کو غیر فعال کریں۔

!!! note "کرسر کی اپنی خصوصیات"
    کرسر کی ایجنٹک خصوصیات OpenAI کے مطابق چیٹ ماڈل کے ساتھ بہترین کام کرتی ہیں۔
    `claudinio` ٹول کالز کو سپورٹ کرتا ہے، لہذا Composer/Agent کے فلو کام کرتے ہیں۔ کچھ
    کرسر کی ملکیتی خصوصیات (Tab آٹوکمپلیٹ، وغیرہ) کرسر کے اپنے ماڈلز پر چلتی ہیں اور آپ کے
    فراہم کنندہ اووررائڈ کے ذریعے روٹ نہیں ہوتیں۔

## تصدیق

کرسر میں چیٹ کھولیں، **claudinio** منتخب کریں، اور ایک پیغام بھیجیں۔ اگر آپ کو جواب ملتا ہے، تو آپ سیٹ ہیں۔ اگر نہیں، تو چیک کریں کہ بنیادی URL `/v1` پر ختم ہوتا ہے اور کلید بغیر اضافی خالی جگہوں کے پیسٹ کی گئی ہے۔

| سیٹنگ | قدر |
| --- | --- |
| بنیادی URL | `https://api.claudin.io/v1` |
| ماڈل | `claudinio` |
