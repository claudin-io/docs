# OpenAI-সামঞ্জস্যপূর্ণ যেকোনো ক্লায়েন্ট

Claudin.io OpenAI API সারফেস বাস্তবায়ন করে, তাই **যেকোনো** টুল, SDK বা লাইব্রেরি যা আপনাকে একটি কাস্টম বেস URL সেট করতে দেয়, কাজ করে। আপনার এডিটর যদি এই বিভাগে তালিকাভুক্ত না থাকে, তাহলে এই জেনেরিক সেটিংস ব্যবহার করুন।

## তিনটি মান

| সেটিং | মান |
| --- | --- |
| বেস URL | `https://api.claudin.io/v1` |
| মডেল | `claudinio` |
| API কী | আপনার `sk-...` কী |

বেশিরভাগ টুল বেস URL ফিল্ডকে এই নামগুলোর একটি বলে: *বেস URL*, *API বেস*, *OpenAI বেস URL*, *এন্ডপয়েন্ট*, অথবা *কাস্টম প্রদানকারী URL*। সর্বদা `/v1` প্রত্যয় অন্তর্ভুক্ত করুন।

## এনভায়রনমেন্ট ভেরিয়েবল

অনেক CLI এবং SDK স্ট্যান্ডার্ড OpenAI ভেরিয়েবলগুলি পড়ে — এগুলি সেট করুন এবং কাজ শেষ। আপনি যদি [আপনার কী এক্সপোর্ট করে থাকেন](../getting-started/set-your-key.md), তাহলে `$CLAUDINIO_API_KEY` পুনরায় ব্যবহার করুন:

```bash
export OPENAI_BASE_URL=https://api.claudin.io/v1
export OPENAI_API_KEY=$CLAUDINIO_API_KEY
```

## সমর্থিত এন্ডপয়েন্ট

Claudin.io এই OpenAI-স্টাইলের পাথগুলি রুট করে:

| এন্ডপয়েন্ট | উদ্দেশ্য |
| --- | --- |
| `POST /v1/chat/completions` | চ্যাট কমপ্লিশন (প্রধানটি) |
| `POST /v1/completions` | লিগ্যাসি টেক্সট কমপ্লিশন |
| `POST /v1/messages` | Anthropic Messages বিন্যাস |
| `POST /v1/responses` | রেসপন্সেস API (Codex দ্বারা ব্যবহৃত) |
| `POST /v1/embeddings` | এম্বেডিংস |
| `GET /v1/models` | উপলব্ধ মডেল তালিকা করুন |

## প্রমাণীকরণ

আপনার কী **নিম্নলিখিত যেকোনো একটি** হিসেবে পাঠান:

```http
Authorization: Bearer YOUR_API_KEY
```

অথবা

```http
x-api-key: YOUR_API_KEY
```

দুটোই গ্রহণ করা হয় — আপনার ক্লায়েন্ট যা নির্গত করে তা বেছে নিন।
