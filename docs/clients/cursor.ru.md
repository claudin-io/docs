# Cursor

[Cursor](https://cursor.com) позволяет добавить совместимую с OpenAI модель через
настройки. Claudin.io подключается через переопределение базового URL OpenAI.

## Настройка

1. Откройте **Cursor → Settings → Models** (или **Cursor Settings → AI**).
2. Прокрутите до **OpenAI API Key** и разверните опцию **Override OpenAI Base URL**.
3. Установите:

    | Поле | Значение |
    | --- | --- |
    | OpenAI API Key | `YOUR_API_KEY` |
    | Base URL | `https://api.claudin.io/v1` |

4. В разделе **Models** добавьте пользовательскую модель с именем **`claudinio`** и включите её.
5. Отключите другие модели по умолчанию, если хотите, чтобы Cursor использовал только Claudin.io.

!!! note "Собственные функции Cursor"
    Агентные функции Cursor лучше всего работают с чат-моделью, совместимой с OpenAI.
    `claudinio` поддерживает вызовы инструментов, поэтому потоки Composer/Agent работают. Некоторые
    проприетарные функции Cursor (Tab autocomplete и т.д.) работают на собственных моделях Cursor
    и не маршрутизируются через ваше переопределение провайдера.

## Проверка

Откройте чат в Cursor, выберите **claudinio** и отправьте сообщение. Если вы получите
ответ, всё настроено. Если нет, перепроверьте, что базовый URL заканчивается на `/v1` и ключ
вставлен без лишних пробелов.

| Параметр | Значение |
| --- | --- |
| Base URL | `https://api.claudin.io/v1` |
| Model | `claudinio` |
