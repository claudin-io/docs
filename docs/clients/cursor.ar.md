# Cursor

يتيح لك [Cursor](https://cursor.com) إضافة نموذج متوافق مع OpenAI من خلال إعداداته. يتم توصيل Claudin.io عبر تجاوز عنوان URL الأساسي لـ OpenAI.

## الإعداد

1. افتح **Cursor → Settings → Models** (أو **Cursor Settings → AI**).
2. قم بالتمرير إلى **OpenAI API Key** وقم بتوسيع خيار **Override OpenAI Base URL**.
3. عيّن:

    | الحقل | القيمة |
    | --- | --- |
    | OpenAI API Key | `YOUR_API_KEY` |
    | عنوان URL الأساسي | `https://api.claudin.io/v1` |

4. ضمن **Models**، أضف نموذجًا مخصصًا باسم **`claudinio`** وقم بتمكينه.
5. عطّل النماذج الافتراضية الأخرى إذا كنت تريد أن يستخدم Cursor Claudin.io بشكل حصري.

!!! note "ميزات Cursor الخاصة"
    تعمل ميزات الوكيل لـ Cursor بشكل أفضل مع نموذج دردشة متوافق مع OpenAI. يدعم `claudinio` استدعاءات الأدوات، لذا فإن تدفقات Composer/Agent تعمل. بعض الميزات الحصرية لـ Cursor (الإكمال التلقائي للتبويب، إلخ) تعمل على نماذج Cursor الخاصة ولا يتم توجيهها من خلال تجاوز مزود الخدمة الخاص بك.

## التحقق

افتح محادثة في Cursor، واختر **claudinio**، وأرسل رسالة. إذا تلقيت ردًا، فأنت جاهز. إذا لم يكن الأمر كذلك، تحقق مرة أخرى من أن عنوان URL الأساسي ينتهي بـ `/v1` وأن المفتاح قد تم لصقه بدون مسافات إضافية.

| الإعداد | القيمة |
| --- | --- |
| عنوان URL الأساسي | `https://api.claudin.io/v1` |
| النموذج | `claudinio` |
