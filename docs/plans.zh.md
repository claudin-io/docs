# 套餐与限制

每个 Claudin.io 套餐都是**无限使用**，并带有**支出保护上限**。
您不会按 token 或按请求付费 — 您支付固定的月费并自由使用。
上限仅用于防止失控的代理（例如无限工具循环）耗尽您的套餐。

    才会触及它 — 而这正是您*想要*刹车的时候。

## 支出保护的工作原理

每个套餐定义一个预算**窗口** — 一个滚动周期和其中的最大支出：

- **入门版**、**轻量版**、**基础版**、**专业版**、**强大版**和**至尊版**使用**1小时**窗口。

在窗口内，您的使用会累积一个微小的内部成本。当该内部成本达到窗口上限时，
请求将暂停，直到窗口重置。

只有您的模型调用通过代理。每个请求根据使用的 token 增加到当前窗口的累计总额。
当窗口重置时，总额也会重置。

如果您达到上限并收到预算错误，您有两个选择：

1. 等待窗口重置（在您的仪表板中显示）。
2. 升级到更高套餐以获得更大的上限。

查看[套餐相关错误](api-reference.md#errors)了解预算错误的外观。
