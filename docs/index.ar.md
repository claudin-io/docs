# كود بدون قلق الفاتورة. سعر شهري ثابت، استخدام غير محدود.

Claudin.io هو وكيل API لوكلاء برمجة الذكاء الاصطناعي. ادفع **اشتراكًا شهريًا ثابتًا** واستخدمه بقدر ما تريد — لا فوترة لكل رمز، لا عدادات طلبات، لا أرصدة تنتهي صلاحيتها.

## لماذا Claudin.io

<div class="grid cards" markdown>

-   :material-infinity:{ .lg .middle } __استخدام غير محدود__

    ---

    لا عدادات طلبات، لا قياس للرموز. الحد الوحيد هو حد **حماية الإنفاق** لكل فترة يوقف الوكيل الجامح — نادرًا ما تصل إليه في العمل العادي.

-   :material-power-plug:{ .lg .middle } __يعمل مع أدواتك__

    ---

    نقاط نهاية متوافقة مع OpenAI وAnthropic. قم بإسقاطها في OpenCode، Claude Code، Kilo Code، Zed، Codex، Cursor، أو أي عميل OpenAI في دقائق.

-   :material-cash-multiple:{ .lg .middle } __تكلفة متوقعة__

    ---

    اشتراك ثابت. لا فواتير مفاجئة في نهاية الشهر، لا قلق "كم ستكلف إعادة الهيكلة هذه؟"

-   :material-shield-check:{ .lg .middle } __حماية إنفاق مدمجة__

    ---

    حد ميزانية متدرج لكل فترة يحميك من الوكلاء ذوي الحلقات اللانهائية التي تحرق خطتك. شفاف ويظهر مباشر في لوحة التحكم الخاصة بك.

</div>

## ابدأ في 4 خطوات

1. **[أنشئ حسابًا](getting-started/account.md)** وانسخ مفتاح API الخاص بك.
2. **[عيّن مفتاح API الخاص بك](getting-started/set-your-key.md)** مرة واحدة في شيلتك.
3. **[ربط أداتك](clients/opencode.md)** — اختر محررك أو وكيلك.
4. **[أجرِ مكالمتك الأولى](getting-started/first-call.md)** وابدأ في البناء.

!!! tip "اسم النموذج دائمًا `claudinio`"
    مهما كان العميل الذي تستخدمه، معرف النموذج الذي توجه إليه هو **`claudinio`**. رابط الأساس هو **`https://api.claudin.io`**.
