# برمِج بلا قلق من الفاتورة. رصيد لا ينتهي أبدًا، وبلا حد بالساعة.

Claudin.io وكيل API لوكلاء البرمجة بالذكاء الاصطناعي. اختر **خطة شهرية**، واحصل على محفظة رصيد تمتلئ كل شهر، وأنفقها بنحو نقطة واحدة للطلب — لا فاتورة لكل رمز، ولا حد بالساعة، وما لا تستخدمه يبقى لك.

## لماذا Claudin.io

<div class="grid cards" markdown>

-   :material-wallet:{ .lg .middle } __رصيد، لا عدّاد__

    ---

    الخطة عدد من نقاط الرصيد في الشهر؛ الطلب النموذجي يكلّف نحو نقطة واحدة. لا
    حد بالساعة ولا حد للجلسة — المحفظة هي الحد الوحيد، والشحنة تملؤها فورًا.

-   :material-power-plug:{ .lg .middle } __يعمل مع أدواتك__

    ---

    نقاط نهاية متوافقة مع OpenAI وAnthropic. أوصله بـ OpenCode أو Claude Code
    أو Kilo Code أو Zed أو Codex أو Cursor أو أي عميل OpenAI في دقائق.

-   :material-cash-multiple:{ .lg .middle } __تكلفة يمكن توقعها__

    ---

    سعر شهري ثابت مقابل عدد معلوم من نقاط الرصيد. لا مفاجآت في فاتورة آخر
    الشهر، والرصيد غير المستخدم يُرحَّل — لا ينتهي أبدًا.

-   :material-format-list-bulleted:{ .lg .middle } __نموذج نضبطه، وكتالوج حين تريد الاختيار__

    ---

    `claudinio` هو الافتراضي وتوصيتنا — النموذج الذي يذهب به رصيدك أبعد ما
    يمكن. ثمانية نماذج مسمّاة على بُعد إعداد واحد، كلٌّ مضاعف ثابت من نقطة
    رصيد `claudinio`.

</div>

## ابدأ في 4 خطوات

1. **[أنشئ حسابًا](getting-started/account.md)** وانسخ مفتاح API.
2. **[اضبط مفتاح API](getting-started/set-your-key.md)** — مرة واحدة في الصدفة (shell).
3. **[اربط أداتك](clients/opencode.md)** — اختر محرّرك أو وكيلك.
4. **[نفّذ أول استدعاء](getting-started/first-call.md)** وابدأ البناء.

!!! tip "اسم النموذج هو `claudinio`"
    أيًّا كان العميل الذي تستخدمه، معرّف النموذج الذي تشير إليه هو
    **`claudinio`** — أو [معرّف من الكتالوج](plans.md#catalogue) حين تريد
    نموذجًا محددًا. عنوان الأساس هو **`https://api.claudin.io`**.
