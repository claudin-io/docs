# FAQ

## Claudin.io আসলে কী?

একটি API প্রক্সি AI কোডিং এজেন্টদের জন্য। আপনি একটি ফ্ল্যাট মাসিক সাবস্ক্রিপশন প্রদান করেন এবং একটি OpenAI/Anthropic-সামঞ্জস্যপূর্ণ API কী পান যা আপনি Claude Code, Kilo, Zed, Codex, Cursor, বা যেকোনো OpenAI ক্লায়েন্টে ব্যবহার করতে পারেন। কোনো প্রতি-টোকেন বিলিং নেই।

## এটি কি সত্যিই সীমাহীন?

ব্যবহার সীমাহীন — কোনো অনুরোধ কাউন্টার বা টোকেন মিটার নেই। একমাত্র সীমা হলো একটি **ব্যয়-সুরক্ষা সীমা** প্রতি সময় উইন্ডোতে যা একটি পলায়নপর এজেন্টকে আপনার প্ল্যান শেষ করা থেকে থামায়। সাধারণ ইন্টারেক্টিভ কাজে আপনি খুব কমই এতে পৌঁছান। দেখুন [প্ল্যান ও সীমা](plans.md)।

## কোডিং ছাড়া অন্য কাজে কি এটি ব্যবহার করতে পারি?

API টি OpenAI-সামঞ্জস্যপূর্ণ, তাই প্রযুক্তিগতভাবে যেকোনো অনুরোধ কাজ করে। কিন্তু
সেবাটি **AI প্রোগ্রামিংয়ের** জন্য তৈরি: রাউটিং, প্রম্পট ও ক্যাশিং সবই কোডিং
এজেন্টের জন্য টিউন করা। প্রোগ্রামিংয়ের সাথে সম্পর্কহীন কার্যকলাপ — সাধারণ চ্যাট
বট, নন-কোডিং অটোমেশন — বিশেষ রাউটিং পেতে পারে এবং কোডিং ট্র্যাফিকের চেয়ে ভিন্ন
মডেল বা স্তর দ্বারা পরিবেশিত হতে পারে।

## আমি কোন মডেল ব্যবহার করব?

সর্বদা **`claudinio`** (অথবা `claudinio/claudinio` ক্লায়েন্টদের জন্য যারা `provider/model` ফর্ম চায়)। বেস URL হলো `https://api.claudin.io`।

## আমি `Authorization` না `x-api-key` দিয়ে প্রমাণীকরণ করব?

যেকোনোটিই কাজ করে। `Authorization: Bearer YOUR_API_KEY` অথবা `x-api-key: YOUR_API_KEY`।

## আমি কি এটি এমন একটি টুলের সাথে ব্যবহার করতে পারি যা তালিকাভুক্ত নয়?

হ্যাঁ — যে কোনো টুল যা আপনাকে একটি কাস্টম OpenAI বেস URL সেট করতে দেয় তা কাজ করে। [সাধারণ OpenAI সেটআপ](clients/openai-compatible.md) ব্যবহার করুন।

## এটি কি টুল / ফাংশন কলিং সমর্থন করে?

হ্যাঁ। এই কারণেই এটি এজেন্টিক এডিটরগুলির ভিতরে কাজ করে। `tools` পাস করুন এবং `tool_calls` পড়ুন যেমন OpenAI API-এর সাথে।

## এটি কি ছবি, অডিও বা ভিডিও হ্যান্ডেল করতে পারে?

হ্যাঁ, স্বচ্ছভাবে। স্ট্যান্ডার্ড OpenAI কন্টেন্ট ব্লক পাঠান; প্রক্সি ছবি/অডিও/ভিডিওকে টেক্সট বর্ণনা বা ট্রান্সক্রিপশনে রূপান্তর করে মডেল সেগুলি দেখার আগে। কনফিগার করার মতো বিশেষ কিছু নেই।

## কনটেক্সট উইন্ডো কত?

256K টোকেন।

## আমি কীভাবে আপগ্রেড বা বাতিল করব?

আপনার [ড্যাশবোর্ড](https://claudin.io/dashboard) থেকে। আপগ্রেড অবিলম্বে প্রযোজ্য (Stripe-এর মাধ্যমে)। আপনি যদি বাতিল করেন, আপনি আপনার পেইড প্ল্যানটি বজায় রাখেন আপনি যে সময়ের জন্য ইতিমধ্যে অর্থ প্রদান করেছেন তার শেষ পর্যন্ত, তারপর স্বয়ংক্রিয়ভাবে Free-তে চলে যান।

## আমি একটি বাজেট ত্রুটির সম্মুখীন হলাম। এখন কী?

আপনি বর্তমান উইন্ডোর ব্যয়-সুরক্ষা সীমায় পৌঁছেছেন। হয় উইন্ডোটি রিসেট হওয়ার জন্য অপেক্ষা করুন (আপনার ড্যাশবোর্ড দেখায় কখন) অথবা একটি বড় সীমার জন্য [আপগ্রেড](plans.md) করুন।

## একটি অনুরোধ 401 দিয়ে ব্যর্থ হয়েছে।

আপনার কী অনুপস্থিত বা ভুল। ড্যাশবোর্ড থেকে এটি পুনরায় কপি করুন এবং নিশ্চিত করুন যে কোনো অতিরিক্ত স্পেস নেই এবং auth হেডার সেট করা আছে।

## আমার কী লিক হয়েছে। আমি কী করব?

ড্যাশবোর্ড থেকে এটি প্রত্যাহার করুন এবং অবিলম্বে একটি নতুন তৈরি করুন। কীগুলোকে পাসওয়ার্ডের মতো আচরণ করুন — কখনোই সেগুলি কমিট করবেন না বা প্রকাশ্যে শেয়ার করবেন না।

## আমি কোথায় সাহায্য পাব?

আপনার [ড্যাশবোর্ড](https://claudin.io/dashboard)-এর **সাপোর্ট** কার্ড থেকে একটি টিকেট খুলুন, অথবা সাপোর্টে ইমেল করুন। আমরা আপনার কাছে ফিরে আসব।
