# API حوالہ

Claudin.io ایک **OpenAI-مطابق** API ہے۔ اگر آپ نے OpenAI API استعمال کیا ہے،
تو یہاں سب کچھ واقف ہے — بس Claudin.io کے بیس URL کی طرف اشارہ کریں اور
`claudinio` ماڈل استعمال کریں۔

## بیس URL

```
https://api.claudin.io
```

OpenAI طرز کے راستے `/v1` کے تحت ہیں۔

## تصدیق

اپنی API کلید ہر درخواست کے ساتھ بھیجیں، بطور ہیڈر:

```http
Authorization: Bearer YOUR_API_KEY
```

```http
x-api-key: YOUR_API_KEY
```

## ماڈل

| ماڈل شناخت | سیاق و سباق کی ونڈو |
| --- | --- |
| `claudinio` | 256K ٹوکنز |

`claudinio` ہر جگہ استعمال کریں۔ (کچھ کلائنٹس `provider/model` فارم کی توقع رکھتے ہیں — ان کے لیے `claudinio/claudinio` استعمال کریں۔)

## اینڈ پوائنٹس

| طریقہ اور راستہ | تفصیل |
| --- | --- |
| `POST /v1/chat/completions` | چیٹ مکمل کرنا — بنیادی اینڈ پوائنٹ |
| `POST /v1/completions` | لیگیسی ٹیکسٹ مکمل کرنا |
| `POST /v1/messages` | Anthropic Messages فارمیٹ |
| `POST /v1/responses` | Responses API (Codex) |
| `POST /v1/embeddings` | ٹیکسٹ ایمبیڈنگز |
| `GET /v1/models` | دستیاب ماڈلز کی فہرست |

### چیٹ مکمل کرنا

```bash
curl https://api.claudin.io/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_API_KEY" \
  -d '{
    "model": "claudinio",
    "messages": [
      {"role": "system", "content": "You are a helpful assistant."},
      {"role": "user", "content": "Write a haiku about proxies."}
    ],
    "temperature": 0.7
  }'
```

معیاری OpenAI پیرامیٹرز تعاون یافتہ ہیں: `messages`, `temperature`, `top_p`,
`max_tokens`, `stream`, `stop`, `tools` / `tool_choice` (فنکشن کالنگ)،
`response_format`، وغیرہ۔

### `max_tokens` اور استدلال

Claudinio ماڈل جواب دینے سے پہلے استدلال کرتے ہیں، اور **استدلال کے ٹوکنز
`max_tokens` کے حساب میں شمار ہوتے ہیں** — ایک ہی بجٹ اندرونی سوچ کے سلسلے اور
ظاہری جواب دونوں کا احاطہ کرتا ہے۔ لہٰذا ایک چھوٹا `max_tokens` تقریباً
مکمل طور پر استدلال پر خرچ ہو سکتا ہے، جس سے جواب درمیانی جملے میں کٹا رہ
جاتا ہے۔

اس کو روکنے کے لیے، **4000** سے کم اقدار خود بخود 4000 تک بڑھا دی جاتی ہیں۔
بڑی اقدار کو بغیر تبدیلی کے منتقل کیا جاتا ہے، اور پیرامیٹر کو چھوڑنا
ہمیشہ ٹھیک ہے۔

اگر آپ ساختی آؤٹ پٹ (JSON، XML، ایک سخت فارمیٹ) کو پارس کرتے ہیں، تو پارس
کرنے سے پہلے `finish_reason` چیک کریں — `"length"` کا مطلب ہے کہ جواب
ٹوکن کی حد کو چھو گیا ہے اور نامکمل ہے، لہٰذا پارس کرنے میں ناکامی ایک
توقع شدہ مسئلہ ہے نہ کہ خراب ماڈل کا مسئلہ:

```python
choice = response.choices[0]
if choice.finish_reason == "length":
    ...  # truncated — retry with a larger max_tokens
data = json.loads(choice.message.content)
```

### اسٹریمنگ

`"stream": true` سیٹ کریں تاکہ OpenAI اسٹریمنگ فارمیٹ میں سرور سے بھیجے گئے
واقعات موصول ہوں (`data: {...}` کے ٹکڑے جو `data: [DONE]` کے ذریعے ختم ہوتے ہیں)۔

### ٹول / فنکشن کالنگ

`claudinio` ٹول کالز کو سپورٹ کرتا ہے۔ `tools` پاس کریں اور `tool_calls` کو
جواب سے واپس پڑھیں، بالکل اسی طرح جیسے OpenAI API کے ساتھ۔ یہی وہ چیز ہے
جو اسے Claude Code، Kilo، اور Cursor جیسے ایجنٹ ایڈیٹرز کے اندر کام کرنے
کے قابل بناتی ہے۔

### ملٹی موڈل ان پٹ

`claudinio` ایک ٹیکسٹ ماڈل ہے، لیکن Claudin.io **شفاف طریقے سے** تصاویر،
آڈیو، اور ویڈیو بلاکس کو ہینڈل کرتا ہے: اگر آپ انہیں بھیجتے ہیں، تو
پراکسی انہیں ٹیکسٹ وضاحتوں/نقلوں میں تبدیل کر دیتی ہے اس سے پہلے کہ
ماڈل انہیں دیکھے۔ آپ کو کچھ خاص کرنے کی ضرورت نہیں ہے — معیاری OpenAI
مواد کے بلاکس بھیجیں اور یہ کام کرتا ہے۔

## غلطیاں {#errors}

غلطیاں OpenAI کی غلطی کی شکل کی پیروی کرتی ہیں:

```json
{ "error": { "message": "…", "type": "…", "code": "…" } }
```

| حالت | معنی | کیا کریں |
| --- | --- | --- |
| `401` | غلط یا غائب API کلید | کلید اور تصدیقی ہیڈر چیک کریں |
| `403` | اینڈ پوائنٹ کی اجازت نہیں | تعاون یافتہ `/v1/*` راستوں میں سے ایک استعمال کریں |
| `429` | بجٹ کی حد پہنچ گئی یا شرح محدود | ونڈو ری سیٹ کا انتظار کریں یا [اپ گریڈ کریں](plans.md) |
| `400` | خراب درخواست | اپنا JSON / پیرامیٹرز چیک کریں |
| `5xx` | اپ اسٹریم/پرووائیڈر کی خرابی | بیک آف کے ساتھ دوبارہ کوشش کریں |

!!! info "پرووائیڈر کی تفصیلات ڈیزائن کے لحاظ سے پوشیدہ ہیں"
    غلطیوں کے پیغامات کو صاف کیا جاتا ہے تاکہ وہ بنیادی ماڈل پرووائیڈر کو
    ظاہر نہ کریں۔ آپ ہمیشہ Claudin.io-برانڈڈ، OpenAI-شکل کی غلطیاں
    دیکھیں گے۔

### بجٹ کی حد کو چھونا

جب آپ موجودہ ونڈو کے اخراجات کے تحفظ کو ختم کر دیتے ہیں، تو درخواستیں
بجٹ کی خرابی (عام طور پر `429`) لوٹاتی ہیں۔ آپ کا ڈیش بورڈ عین ری سیٹ
کا وقت اور باقی بجٹ دکھاتا ہے۔ دیکھیں [منصوبے اور حدود](plans.md) کہ
ونڈوز کیسے کام کرتی ہیں۔

## شرح کی حد بندی

Claudin.io عام استعمال کو سختی سے نہیں روکتا۔ غلط استعمال کی درخواستوں
کی شرح کو مسترد کرنے کے بجائے *سست* کیا جاتا ہے (ایک شفاف تھروٹل)،
لہٰذا اچھے رویے والے کلائنٹس کو کبھی سزا نہیں دی جاتی۔ عملی طور پر آپ
کو کچھ کرنے کی ضرورت نہیں ہے — صرف نایاب `429` پر دوبارہ کوشش کریں۔
