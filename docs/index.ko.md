# 청구서 걱정 없는 코딩. 만료되지 않는 크레딧, 시간당 한도 없음.

Claudin.io는 AI 코딩 에이전트를 위한 API 프록시입니다. **월간 요금제**를 고르면 매달 채워지는 크레딧 지갑을 받고, 요청당 약 1 크레딧으로 사용합니다 — 토큰당 청구 없음, 시간당 한도 없음, 쓰지 않은 것은 여러분의 것입니다.

## 왜 Claudin.io인가

<div class="grid cards" markdown>

-   :material-wallet:{ .lg .middle } __미터기가 아닌 크레딧__

    ---

    요금제는 월당 크레딧 수이고, 일반적인 요청은 약 1 크레딧입니다. 시간당
    한도도 세션 한도도 없습니다 — 지갑이 유일한 한도이며, 충전으로 즉시
    채워집니다.

-   :material-power-plug:{ .lg .middle } __사용 중인 도구와 호환__

    ---

    OpenAI 및 Anthropic 호환 엔드포인트. OpenCode, Claude Code, Kilo Code, Zed,
    Codex, Cursor 또는 모든 OpenAI 클라이언트에 몇 분 만에 연결하세요.

-   :material-cash-multiple:{ .lg .middle } __예측 가능한 비용__

    ---

    정해진 크레딧 수에 대한 고정 월 요금. 월말 청구서에 놀랄 일이 없고, 쓰지
    않은 크레딧은 이월됩니다 — 절대 만료되지 않습니다.

-   :material-format-list-bulleted:{ .lg .middle } __튜닝한 모델 하나, 선택하고 싶을 때의 카탈로그__

    ---

    `claudinio`가 기본이자 저희의 추천입니다 — 크레딧이 가장 멀리 가는 모델.
    이름 있는 8개 모델은 설정 하나 거리에 있고, 각각 `claudinio` 크레딧의 고정
    배수입니다.

</div>

## 4단계로 시작하기

1. **[계정 만들기](getting-started/account.md)** 후 API 키를 복사합니다.
2. **[API 키 설정](getting-started/set-your-key.md)** — 셸에서 한 번만.
3. **[도구 연결](clients/opencode.md)** — 에디터나 에이전트를 고릅니다.
4. **[첫 호출하기](getting-started/first-call.md)** 그리고 만들기 시작하세요.

!!! tip "모델 이름은 `claudinio`입니다"
    어떤 클라이언트를 쓰든 가리키는 모델 ID는 **`claudinio`**입니다 — 특정
    모델을 원할 때는 [카탈로그 ID](plans.md#catalogue)를. 기본 URL은
    **`https://api.claudin.io`**입니다.
