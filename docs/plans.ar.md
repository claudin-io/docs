# الخطط والحدود

كل خطة من Claudin.io هي **استخدام غير محدود** مع **سقف حماية للإنفاق**.
لا يتم فوترتك حسب الرمز أو الطلب — تدفع سعرًا شهريًا ثابتًا وتستخدمه بحرية. السقف موجود فقط لمنع وكيل خارج عن السيطرة
(حلقة أدوات لا نهائية، على سبيل المثال) من استنزاف خطتك.

## claudinio vs Claudius

|                      | claudinio 🏆         | claudius ★           |
| -------------------- | -------------------- | -------------------- |
| **Starter**          | ✅                   |                      |
| **Lite**             | ✅                   |                      |
| **Essential**        | ✅                   | ✅                   |
| **Pro**              | ✅                   | ✅                   |
| **Power**            | ✅                   | ✅                   |
| **Ultra**            | ✅                   | ✅                   |

> **أفضل قيمة مقابل مالك.**

### لـ Starter / Lite: استخدم claudinio

إذا كنت تستخدم Starter أو Lite، فإن claudinio هو النموذج الذي ستستخدمه. وبصراحة؟ لست بحاجة للنظر إلى الوراء. claudinio ينافس النماذج الرائدة بتكلفة بسيطة — مما يجعله مثالياً للبرمجة اليومية والتعلم والمشاريع الشخصية.

### لـ Essential وما فوق: العالم بين يديك

Essential وما فوق يمنحك الوصول إلى كل من claudinio و claudius. استخدم claudinio لمهامك اليومية واحتفظ بـ claudius للأوقات التي تحتاج فيها إلى شرارة إضافية — الهندسة المعمارية المعقدة، التفكير العميق، أو جلسات تصحيح الأخطاء الصعبة.

### لكن تذكر القاعدة الذهبية

بغض النظر عن خطتك، نوصي بجعل claudinio نموذجك الافتراضي. إنه نموذجنا الرائد، ونحن نؤمن به. يمكنك دائماً التبديل إلى claudius عندما تتطلب المهمة ذلك.

### أسماء مستعارة للنماذج

جميع الخطط تدعم الأسماء المستعارة للنماذج الشائعة مثل: `claude-sonnet-4`، `gpt-4o`، `gemini-2.5-pro`، `llama-4`، `deepseek-v4`. اطلع على [API Reference](/api-reference/) الخاص بنا للقائمة الكاملة.

## كيف تعمل حماية الإنفاق

تحدد كل خطة **نافذة** ميزانية — فترة متجددة وأقصى إنفاق داخلها:

- **مبتدئ**، **خفيف**، **أساسي**، **محترف**، **قوي**، و**فائق** تستخدم نافذة **1 ساعة**.

داخل النافذة، يتراكم استخدامك تكلفة داخلية صغيرة. عندما تصل هذه التكلفة
الداخلية إلى سقف النافذة، تتوقف الطلبات حتى تعاد النافذة.

فقط مكالمات نموذجك من خلال الوكيل. كل طلب يضيف إلى إجمالي النافذة الحالي
بناءً على الرموز المستخدمة. عندما تعاد النافذة، يعاد تعيين الإجمالي معها.

إذا وصلت إلى السقف وحصلت على خطأ في الميزانية، لديك خياران:

1. انتظر حتى تعاد النافذة (كما هو موضح في لوحة التحكم الخاصة بك).
2. الترقية إلى خطة أعلى للحصول على سقف أكبر.

انظر [الأخطاء المتعلقة بالخطط](api-reference.md#errors) لمعرفة شكل خطأ الميزانية.
