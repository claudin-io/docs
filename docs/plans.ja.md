# プランと制限

すべてのClaudin.ioプランは**無制限利用**で**支出保護キャップ**付きです。
トークンやリクエストごとに請求されることはありません — 定額の月額料金を支払い、
自由に使用できます。キャップは、暴走したエージェント（無限ツールループなど）が
プランを枯渇させるのを防ぐためだけに存在します。

> **最高のコストパフォーマンス。**

### Starter / Lite向け：claudinioを使用

StarterまたはLiteをご利用の場合、claudinioが使用するモデルです。正直なところ？振り返る必要はありません。claudinioは最先端モデルに引けを取らず、価格はそのほんの一部 — 日常的なコーディング、学習、趣味のプロジェクトに最適です。

### Essential以上向け：世界はあなたのもの

Essential以上のプランでは、claudinioとclaudiusの両方にアクセスできます。日常のタスクにはclaudinioを使用し、複雑なアーキテクチャ、深い推論、難しいデバッグセッションなど、特別な力が必要な時にclaudiusを取っておきましょう。

### でもね、黄金律

どのプランでも、claudinioをデフォルトモデルにすることをお勧めします。それが私たちの看板モデルであり、私たちはそれを信じています。タスクが必要とするときはいつでもclaudiusに切り替えられます。

### モデルエイリアス

すべてのプランで人気モデルのエイリアスをサポートしています：`claude-sonnet-4`、`gpt-4o`、`gemini-2.5-pro`、`llama-4`、`deepseek-v4`。完全なリストは[API Reference](/api-reference/)をご覧ください。

## 支出保護の仕組み

各プランは予算**ウィンドウ** — ローリング期間とその中の最大支出を定義します：

- **スターター**、**ライト**、**エッセンシャル**、**プロ**、**パワー**、**ウルトラ**は**1時間**ウィンドウを使用します。

ウィンドウ内では、使用量に応じて小さな内部コストが蓄積されます。その内部コストが
ウィンドウのキャップに達すると、ウィンドウがリセットされるまでリクエストが一時停止されます。

モデル呼び出しのみがプロキシを通過します。各リクエストは、使用されたトークンに基づいて
現在のウィンドウの累計に追加されます。ウィンドウがリセットされると、累計もリセットされます。

キャップに達して予算エラーが発生した場合、2つのオプションがあります：

1. ウィンドウがリセットされるのを待つ（ダッシュボードに表示されます）。
2. より大きなキャップのために上位プランにアップグレードする。

予算エラーの外観については、[プラン関連エラー](api-reference.md#errors)を参照してください。
