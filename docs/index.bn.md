# বিলের দুশ্চিন্তা ছাড়াই কোড করুন। ক্রেডিটের মেয়াদ কখনও শেষ হয় না, ঘণ্টাভিত্তিক সীমা নেই।

Claudin.io হলো AI কোডিং এজেন্টের জন্য একটি API প্রক্সি। একটি **মাসিক প্ল্যান** বেছে নিন, প্রতি মাসে ভরে যাওয়া একটি ক্রেডিট ওয়ালেট পান, আর প্রতি অনুরোধে প্রায় এক ক্রেডিটে খরচ করুন — প্রতি টোকেনে বিল নেই, ঘণ্টাভিত্তিক সীমা নেই, আর যা ব্যবহার করেননি তা আপনারই থাকে।

## 4 ধাপে শুরু করুন

1. **[অ্যাকাউন্ট তৈরি করুন](getting-started/account.md)** আর আপনার API কী কপি করুন।
2. **[API কী সেট করুন](getting-started/set-your-key.md)** — শেলে একবার।
3. **[টুল যুক্ত করুন](clients/opencode.md)** — আপনার এডিটর বা এজেন্ট বেছে নিন।
4. **[প্রথম কল করুন](getting-started/first-call.md)** আর বানানো শুরু করুন।

!!! tip "মডেলের নাম `claudinio`"
    যে ক্লায়েন্টই ব্যবহার করুন, যে মডেল আইডির দিকে নির্দেশ করবেন তা
    **`claudinio`** — বা নির্দিষ্ট মডেল চাইলে একটি
    [ক্যাটালগ আইডি](plans.md#catalogue)। বেস URL **`https://api.claudin.io`**।
