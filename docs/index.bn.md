# বিলের উদ্বেগ ছাড়াই কোড করুন। ফ্ল্যাট মাসিক মূল্য, সীমাহীন ব্যবহার।

Claudin.io হলো AI কোডিং এজেন্টদের জন্য একটি API প্রক্সি। একটি **ফ্ল্যাট মাসিক সাবস্ক্রিপশন** প্রদান করুন এবং যত খুশি তত ব্যবহার করুন — কোনো প্রতি-টোকেন বিলিং নেই, কোনো অনুরোধ কাউন্টার নেই, কোনো ক্রেডিটের মেয়াদ শেষ হয় না।

## কেন Claudin.io

<div class="grid cards" markdown>

-   :material-infinity:{ .lg .middle } __সীমাহীন ব্যবহার__

    ---

    কোনো অনুরোধ গণনা নেই, কোনো টোকেন মিটারিং নেই। একমাত্র প্রতিবন্ধক হলো একটি প্রতি-পর্যায়ের **ব্যয় সুরক্ষা** সীমা যা একটি অনিয়ন্ত্রিত এজেন্টকে থামায় — আপনি সাধারণ কাজে এটি প্রায় কখনোই আঘাত করেন না।

-   :material-power-plug:{ .lg .middle } __আপনার টুলের সাথে কাজ করে__

    ---

    OpenAI এবং Anthropic-সঙ্গতিপূর্ণ এন্ডপয়েন্ট। মিনিটের মধ্যে এটি OpenCode, Claude Code, Kilo Code, Zed, Codex, Cursor, বা যেকোনো OpenAI ক্লায়েন্টে যুক্ত করুন।

-   :material-cash-multiple:{ .lg .middle } __পূর্বানুমানযোগ্য খরচ__

    ---

    একটি নির্দিষ্ট সাবস্ক্রিপশন। মাসের শেষে কোনো অপ্রত্যাশিত বিল নেই, 'এই রিফ্যাক্টরের খরচ কত হবে?' এই উদ্বেগ নেই।

-   :material-shield-check:{ .lg .middle } __নির্মিত ব্যয় সুরক্ষা__

    ---

    একটি ক্রমিক প্রতি-পর্যায়ের বাজেট ক্যাপ আপনাকে অসীম-লুপ এজেন্টদের আপনার প্ল্যান পুড়িয়ে ফেলা থেকে রক্ষা করে। স্বচ্ছ এবং আপনার ড্যাশবোর্ডে লাইভ দেখানো হয়।

## 4টি ধাপে শুরু করুন

1. **[একটি অ্যাকাউন্ট তৈরি করুন](getting-started/account.md)** এবং আপনার API কী কপি করুন।
2. **[আপনার API কী সেট করুন](getting-started/set-your-key.md)** একবার আপনার শেলে।
3. **[আপনার টুল সংযুক্ত করুন](clients/opencode.md)** — আপনার এডিটর বা এজেন্ট বেছে নিন।
4. **[আপনার প্রথম কল করুন](getting-started/first-call.md)** এবং বিল্ডিং শুরু করুন।

!!! tip "মডেলের নাম সর্বদা `claudinio`"
    আপনি যে ক্লায়েন্টই ব্যবহার করুন, আপনি যে মডেল আইডি নির্দেশ করেন তা হলো **`claudinio`**।
    বেস URL হলো **`https://api.claudin.io`**।
