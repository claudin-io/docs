# بل کی فکر کے بغیر کوڈ کریں۔ کریڈٹس، حدیں نہیں۔

Claudin.io AI کوڈنگ ایجنٹس کے لیے ایک API پراکسی ہے۔ ایک **ماہانہ منصوبہ** چنیں، ہر مہینے بھرنے والا کریڈٹ والٹ پائیں، اور اسے فی درخواست تقریباً ایک کریڈٹ پر خرچ کریں — فی ٹوکن بل نہیں، فی گھنٹہ حد نہیں۔ آپ کے منصوبے کے کریڈٹس ہر مہینے تجدید ہوتے ہیں — وہ اس مہینے کا کوٹہ ہیں اور جمع نہیں ہوتے۔ ٹاپ اپ کے طور پر خریدے گئے کریڈٹس کبھی ختم نہیں ہوتے۔

    کریڈٹ کی ہوتی ہے۔ کوئی فی گھنٹہ حد نہیں، کوئی سیشن حد نہیں — والٹ ہی واحد

    کوئی حیرت نہیں۔ منصوبے کے کریڈٹس ہر بل کے ساتھ تجدید ہوتے ہیں اور جمع نہیں ہوتے؛

    ---

    `claudinio` ڈیفالٹ اور ہماری سفارش ہے — وہ ماڈل جس پر آپ کے کریڈٹس سب سے

## 4 مراحل میں شروع کریں

1. **[اکاؤنٹ بنائیں](getting-started/account.md)** اور اپنی API کلید کاپی کریں۔
2. **[اپنی API کلید سیٹ کریں](getting-started/set-your-key.md)** — اپنے شیل میں ایک بار۔
3. **[اپنا ٹول جوڑیں](clients/opencode.md)** — اپنا ایڈیٹر یا ایجنٹ چنیں۔
4. **[اپنی پہلی کال کریں](getting-started/first-call.md)** اور بنانا شروع کریں۔

!!! tip "ماڈل کا نام `claudinio` ہے"
    آپ جو بھی کلائنٹ استعمال کریں، جس ماڈل آئی ڈی کی طرف آپ اشارہ کرتے ہیں وہ
    **`claudinio`** ہے — یا جب آپ کوئی مخصوص ماڈل چاہیں تو ایک
    [کیٹلاگ آئی ڈی](plans.md#catalogue)۔ بیس URL **`https://api.claudin.io`** ہے۔
