## کیوں Claudin.io

<div class="grid cards" markdown>

-   :material-infinity:{ .lg .middle } __لامحدود استعمال__

    ---

    کوئی درخواست شمار نہیں، کوئی ٹوکن میٹرنگ نہیں۔ واحد حفاظتی اقدام ایک مدت کے لیے **خرچ کی حفاظت** کی حد ہے جو بھاگنے والے ایجنٹ کو روکتی ہے — آپ عام کام میں اسے تقریباً کبھی نہیں چھوتے۔

-   :material-power-plug:{ .lg .middle } __آپ کے ٹولز کے ساتھ کام کرتا ہے__

    ---

    OpenAI- اور Anthropic-مطابق اینڈ پوائنٹس۔ اسے OpenCode, Claude Code, Kilo Code, Zed, Codex, Cursor، یا کسی بھی OpenAI کلائنٹ میں منٹوں میں ڈال دیں۔

-   :material-cash-multiple:{ .lg .middle } __متوقع لاگت__

    ---

    ایک مقررہ سبسکرپشن۔ مہینے کے آخر میں کوئی حیران کن بل نہیں، کوئی "اس ری فیکٹرنگ کی قیمت کتنی ہوگی؟" کی پریشانی نہیں۔

-   :material-shield-check:{ .lg .middle } __خرچ کی حفاظت بلٹ ان__

    ---

    ایک متواتر مدت کے بجٹ کی حد آپ کو لامتناہی لوپ ایجنٹس سے بچاتی ہے جو آپ کا منصوبہ جلا دیتے ہیں۔ شفاف اور آپ کے ڈیش بورڈ میں لائیو دکھایا جاتا ہے۔

</div>

## 4 مراحل میں شروع کریں

1. **[اکاؤنٹ بنائیں](getting-started/account.md)** اور اپنی API کلید کاپی کریں۔
2. **[اپنی API کلید سیٹ کریں](getting-started/set-your-key.md)** اپنے شیل میں ایک بار۔
3. **[اپنا ٹول منسلک کریں](clients/opencode.md)** — اپنا ایڈیٹر یا ایجنٹ منتخب کریں۔
4. **[اپنی پہلی کال کریں](getting-started/first-call.md)** اور تعمیر شروع کریں۔
