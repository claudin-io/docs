# FAQ

## Claudin.io کیا ہے، بالکل؟

AI کوڈنگ ایجنٹس کے لیے ایک API پراکسی۔ آپ ایک ماہانہ فلیٹ سبسکرپشن ادا کرتے ہیں اور ایک OpenAI/Anthropic کے ساتھ مطابقت رکھنے والی API کلید حاصل کرتے ہیں جسے آپ Claude Code, Kilo, Zed, Codex, Cursor یا کسی بھی OpenAI کلائنٹ میں استعمال کر سکتے ہیں۔ فی ٹوکن بلنگ نہیں۔

## کیا یہ واقعی لامحدود ہے؟

استعمال لامحدود ہے — اس میں کوئی درخواست شمار کنندہ یا ٹوکن میٹر نہیں ہے۔ واحد حد **فی وقت کی مدت میں اخراجات سے تحفظ کی حد** ہے جو ایک بے قابو ایجنٹ کو آپ کے پلان کو ختم کرنے سے روکتی ہے۔ عام انٹرایکٹو کام میں آپ شاذ و نادر ہی اس تک پہنچتے ہیں۔ دیکھیں [منصوبے اور حدود](plans.md)۔

## میں کون سا ماڈل استعمال کروں؟

ہمیشہ **`claudinio`** (یا `claudinio/claudinio` ان کلائنٹس کے لیے جو `provider/model` فارم چاہتے ہیں)۔ بنیادی URL `https://api.claudin.io` ہے۔

## کیا میں `Authorization` یا `x-api-key` سے تصدیق کروں؟

دونوں کام کرتے ہیں۔ `Authorization: Bearer YOUR_API_KEY` یا `x-api-key: YOUR_API_KEY`۔

## کیا میں اسے کسی ایسے ٹول کے ساتھ استعمال کر سکتا ہوں جو فہرست میں نہیں ہے؟

جی ہاں — کوئی بھی ٹول جو آپ کو OpenAI کا حسب ضرورت بنیادی URL سیٹ کرنے دیتا ہے، کام کرتا ہے۔ [عام OpenAI سیٹ اپ](clients/openai-compatible.md) استعمال کریں۔

## کیا یہ ٹول / فنکشن کالنگ کو سپورٹ کرتا ہے؟

جی ہاں۔ اسی وجہ سے یہ ایجنٹک ایڈیٹرز کے اندر کام کرتا ہے۔ `tools` پاس کریں اور `tool_calls` پڑھیں جیسے OpenAI API کے ساتھ۔

## کیا یہ تصاویر، آڈیو، یا ویڈیو کو ہینڈل کر سکتا ہے؟

جی ہاں، شفاف طریقے سے۔ معیاری OpenAI مواد کے بلاکس بھیجیں؛ پراکسی تصاویر/آڈیو/ویڈیو کو متن کی وضاحتوں یا نقلوں میں تبدیل کرتی ہے اس سے پہلے کہ ماڈل انہیں دیکھے۔ کنفیگر کرنے کے لیے کچھ خاص نہیں ہے۔

## سیاق و سباق کی ونڈو کیا ہے؟

256K ٹوکنز۔

## میں کس طرح اپ گریڈ یا منسوخ کروں؟

اپنے [dashboard](https://claudin.io/dashboard) سے۔ اپ گریڈ فوری طور پر لاگو ہوتے ہیں (Stripe کے ذریعے)۔ اگر آپ منسوخ کرتے ہیں، تو آپ اپنا ادا شدہ پلان اس مدت کے اختتام تک رکھتے ہیں جس کے لیے آپ نے پہلے ہی ادائیگی کی ہے، پھر خود بخود Free میں تبدیل ہو جاتے ہیں۔

## مجھے بجٹ کی خرابی ملی۔ اب کیا ہوگا؟

آپ موجودہ ونڈو کی اخراجات سے تحفظ کی حد تک پہنچ گئے ہیں۔ یا تو ونڈو کے ری سیٹ ہونے کا انتظار کریں (آپ کا ڈیش بورڈ دکھاتا ہے کب) یا ایک بڑی حد کے لیے [upgrade](plans.md) کریں۔

## 401 کے ساتھ ایک درخواست ناکام ہوئی۔

آپ کی کلید غائب یا غلط ہے۔ اسے ڈیش بورڈ سے دوبارہ کاپی کریں اور یقینی بنائیں کہ کوئی اضافی خالی جگہ نہیں ہے، اور یہ کہ تصدیقی ہیڈر سیٹ ہے۔

## میری کلید لیک ہو گئی۔ میں کیا کروں؟

اسے ڈیش بورڈ سے منسوخ کریں اور فوری طور پر ایک نئی کلید بنائیں۔ کلیدوں کو پاس ورڈ کی طرح سمجھیں — انہیں کبھی کمٹ نہ کریں یا عوامی طور پر شیئر نہ کریں۔

## مجھے مدد کہاں سے ملے گی؟

اپنے [dashboard](https://claudin.io/dashboard) میں **Support** کارڈ سے ایک ٹکٹ کھولیں، یا سپورٹ کو ای میل کریں۔ ہم آپ سے رابطہ کریں گے۔
