# عمومی سوالات

## Claudin.io بالکل کیا ہے؟

AI کوڈنگ ایجنٹس کے لیے ایک API پراکسی۔ آپ ایک ماہانہ منصوبے کی ادائیگی کرتے
ہیں، ہر مہینے بھرنے والا کریڈٹ والٹ اور ایک OpenAI/Anthropic-مطابق API کلید
پاتے ہیں جسے آپ Claude Code، Kilo، Zed، Codex، Cursor یا کسی بھی OpenAI کلائنٹ
میں استعمال کر سکتے ہیں۔ ایک عام کوڈنگ درخواست تقریباً ایک کریڈٹ کی ہوتی ہے۔
فی ٹوکن بل نہیں، فی گھنٹہ حد نہیں۔

## کیا کوئی حد ہے؟

صرف آپ کا والٹ۔ کوئی فی گھنٹہ حد، سیشن حد یا ہفتہ وار کوٹہ نہیں — آپ کے ایجنٹ کو
روکنے والی واحد چیز خالی بیلنس ہے، اور ایک ٹاپ اپ اسے فوراً ٹھیک کر دیتا ہے۔ جو
کریڈٹس آپ استعمال نہیں کرتے وہ والٹ میں رہتے ہیں اور کبھی ختم نہیں ہوتے۔ دیکھیں
[منصوبے اور کریڈٹس](plans.md)۔

## مقررہ قیمت کے بجائے کریڈٹس کیوں؟

کیونکہ ہم نے مقررہ قیمت والے منصوبوں کی فی گھنٹہ حد کو حقیقی ٹریفک پر ناپا اور
وہ Pro پر ہر 10 فعال گھنٹوں میں سے 1 کو کاٹ رہی تھی — کام کے بیچ میں لوگوں کو،
بے قابو لوپس کو نہیں۔ جو منصوبہ ایسی صلاحیت بیچتا ہے جو ضرورت کے وقت استعمال نہ
ہو سکے، اس کی شکل ہی غلط ہے۔ کریڈٹس ایک عدد ہیں جو آپ دیکھتے ہیں، ایک بھاری
گھنٹہ جس کی ادائیگی پرسکون گھنٹے کرتے ہیں، اور ایک بھاری مہینہ جو انتظار کے
بجائے ایک ٹاپ اپ کے فاصلے پر ہے۔

## کیا میں اسے کوڈنگ کے علاوہ کسی اور کام کے لیے استعمال کر سکتا ہوں؟

API OpenAI-مطابق ہے، اس لیے تکنیکی طور پر کوئی بھی درخواست کام کرتی ہے۔ لیکن
سروس **AI پروگرامنگ** کے لیے بنی ہے: روٹنگ، پرامپٹس اور کیشنگ کوڈنگ ایجنٹس کے
لیے ٹیون ہیں۔ غیر پروگرامنگ سرگرمی — عمومی چیٹ بوٹس، بغیر کوڈ کی آٹومیشن — کو
خصوصی روٹنگ مل سکتی ہے اور اسے کوڈنگ ٹریفک سے مختلف ماڈل یا درجے سے پیش کیا
جا سکتا ہے۔

## میں کون سا ماڈل استعمال کرتا ہوں؟

بطور ڈیفالٹ **`claudinio`** (یا `provider/model` شکل چاہنے والے کلائنٹس کے لیے
`claudinio/claudinio`)۔ بیس URL `https://api.claudin.io` ہے۔ یہ وہ ماڈل ہے جسے
ہم کوڈ کے لیے ٹیون، ناپتے اور کیش کرتے ہیں، اور جس پر آپ کے کریڈٹس سب سے دور
جاتے ہیں۔

## کیا میں کوئی دوسرا ماڈل چن سکتا ہوں؟

ہاں، نام سے۔ `claudius` ہمارا پریمیم آپشن ہے، 6× تک کریڈٹس پر۔
[کیٹلاگ](plans.md#catalogue) آٹھ تیسرے فریق کے ماڈل شامل کرتا ہے — Claude
Sonnet 5 اور Haiku 4.5، Gemini 3.1 Pro، Kimi K3، GLM 5.3، MiniMax M3، Qwen3
Coder — ہر ایک کی قیمت `claudinio` کریڈٹس کے مقررہ ضرب کے طور پر، 3× سے 22×
تک۔ اپنے کلائنٹ میں آئی ڈی سیٹ کریں اور صرف وہی درخواست ضرب ادا کرتی ہے۔ ہر
ماڈل ہر منصوبے پر ہے؛ ہم اب بھی `claudinio` کی سفارش کرتے ہیں۔

## میں `Authorization` سے تصدیق کروں یا `x-api-key` سے؟

دونوں کام کرتے ہیں۔ `Authorization: Bearer YOUR_API_KEY` یا
`x-api-key: YOUR_API_KEY`۔

## کیا میں اسے کسی ایسے ٹول کے ساتھ استعمال کر سکتا ہوں جو فہرست میں نہیں؟

ہاں — کوئی بھی ٹول جو کسٹم OpenAI بیس URL سیٹ کرنے دیتا ہے، کام کرتا ہے۔
[عمومی OpenAI سیٹ اپ](clients/openai-compatible.md) استعمال کریں۔

## کیا یہ ٹول / فنکشن کالنگ کی حمایت کرتا ہے؟

ہاں۔ اسی لیے یہ ایجنٹک ایڈیٹرز میں کام کرتا ہے۔ OpenAI API کی طرح `tools` پاس
کریں اور `tool_calls` پڑھیں۔

## کیا یہ تصاویر، آڈیو یا ویڈیو سنبھال سکتا ہے؟

ہاں، شفاف طور پر۔ معیاری OpenAI کنٹینٹ بلاکس بھیجیں؛ پراکسی ماڈل کے دیکھنے سے
پہلے تصاویر/آڈیو/ویڈیو کو متنی تفصیل یا ٹرانسکرپشن میں بدل دیتا ہے۔ کچھ خاص
کنفیگر کرنے کی ضرورت نہیں۔

## کانٹیکسٹ ونڈو کتنی ہے؟

256K ٹوکن۔

## میں اپ گریڈ یا منسوخ کیسے کروں؟

اپنے [ڈیش بورڈ](https://claudin.io/dashboard) سے۔ اپ گریڈ فوراً لاگو ہوتے ہیں
(Stripe کے ذریعے)۔ اگر آپ منسوخ کرتے ہیں تو پہلے سے ادا شدہ مدت کے اختتام تک
اپنا ادا شدہ منصوبہ رکھتے ہیں۔ جو کریڈٹس پہلے سے والٹ میں ہیں وہ آپ کے رہتے ہیں
اور منصوبہ ختم ہونے کے بعد بھی کام کرتے رہتے ہیں۔

## کیا مجھے رقم واپس مل سکتی ہے؟

**اپنی پہلی ادائیگی کے 48 گھنٹوں کے اندر**، ہاں — اپنے اکاؤنٹ کے ای میل سے
[support@claudin.io](mailto:support@claudin.io) پر لکھیں۔ سبسکرپشن فوراً ختم ہو
جاتی ہے اور آپ کو ادا شدہ رقم واپس ملتی ہے، جس میں سے ایک استعمال اور پروسیسنگ
فیس کاٹی جاتی ہے جو اس مدت میں آپ کے اکاؤنٹ کے ماڈل استعمال کی لاگت پوری کرتی
ہے (کبھی آپ کی ادا شدہ رقم سے زیادہ نہیں)۔ ایک دن آزمایا اور آپ کے لیے نہیں
تھا؟ تقریباً سب واپس ملتا ہے۔ دو دن میں پورے مہینے کے کریڈٹس خرچ کر دیے؟ تھوڑے
یا کچھ نہیں کی توقع رکھیں۔ 48 گھنٹوں کے بعد کوئی واپسی نہیں؛ منسوخی آپ کا
منصوبہ ادا شدہ مدت کے اختتام تک رکھتی ہے۔ مکمل متن
[شرائط](https://claudin.io/terms) میں۔

## مجھے `402 insufficient_credits` ملا۔ اب کیا؟

آپ کا والٹ خالی ہے۔ ڈیش بورڈ سے ایک [ٹاپ اپ](plans.md#top-ups) خریدیں یا بڑے
منصوبے پر جائیں — دونوں فوراً لاگو ہوتے ہیں۔ کچھ بھی قطار میں نہیں گیا، اور
ناکام درخواست کے لیے کچھ بھی چارج نہیں ہوا۔

## میرے پرانے Essential / Pro / Ultra منصوبے کا کیا ہوگا؟

وہ بالکل پہلے کی طرح چلتا رہتا ہے: وہی قیمت، وہی فی گھنٹہ حد، اور وہ معمول کے
مطابق تجدید ہوتا رہتا ہے۔ آپ اب بھی ڈیش بورڈ سے Essential، Pro اور Ultra کے
درمیان بدل سکتے ہیں، اور آپ کی API کلید نہیں بدلتی۔ فی گھنٹہ منصوبے `claudinio`
استعمال کرتے ہیں؛ `claudius` اور ماڈل کیٹلاگ کریڈٹ منصوبوں کے ساتھ آتے ہیں، اس
لیے فی گھنٹہ منصوبے پر ان کا نام لینے والی درخواست کو `claudinio` سنبھالتا ہے۔
دیکھیں [پرانے منصوبے](plans.md#legacy-plans)۔

## ایک درخواست 401 کے ساتھ ناکام ہو گئی۔

آپ کی کلید غائب یا غلط ہے۔ اسے ڈیش بورڈ سے دوبارہ کاپی کریں اور یقینی بنائیں کہ
کوئی اضافی اسپیس نہیں اور آتھ ہیڈر سیٹ ہے۔

## میری کلید لیک ہو گئی۔ کیا کروں؟

اسے ڈیش بورڈ سے منسوخ کریں اور فوراً نئی بنائیں۔ کلیدوں کو پاس ورڈ کی طرح
سمجھیں — انہیں کبھی کمٹ نہ کریں اور عوامی طور پر شیئر نہ کریں۔

## مجھے مدد کہاں ملے گی؟

اپنے [ڈیش بورڈ](https://claudin.io/dashboard) میں **سپورٹ** کارڈ سے ٹکٹ کھولیں،
یا سپورٹ کو ای میل کریں۔ ہم آپ سے رابطہ کریں گے۔
